# 框架效应
> "90%存活率" vs "10%死亡率"——同一件事，不同选择。

## 核心
- 收益框架→风险回避
- 损失框架→风险寻求
- 你的决策可能被"怎么说"而非"是什么"影响

## 你的对照
- 你的提问设计=框架设计（改变AI的框架→改变AI的回答）
