# 自我决定理论
> 人需要三样东西才能持续投入：自主选择的感觉、我能做好的感觉、被连接的感觉。

## 三大需求
| 需求 | 含义 | 被满足时 |
|------|------|---------|
| 自主性 | 感到选择是自己的 | 内在动机 |
| 胜任感 | 感到能应对挑战 | 心流 |
| 关联感 | 感到与他人连接 | 归属感 |

## 你的对照
- 6科并行自学 = 自主性极高
- 打脸链路 = 胜任感循环（预测→验证→成长）
- 英仔爱心社 = 关联感
