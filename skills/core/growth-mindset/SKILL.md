# 成长心态
> "我还没学会" ≠ "我学不会"

## 两种心态
| | 固定心态 | 成长心态 |
|--|---------|---------|
| 面对挑战 | 回避 | 拥抱 |
| 面对失败 | 定义了自己 | 是学习机会 |
| 面对努力 | 无能的表现 | 成长的途径 |
| 面对批评 | 忽略/防御 | 从中学习 |

## 你的对照
- 你已经在用成长心态——高中数学差→自学6科→博士
- 你的"低自信"是固定心态的残余——需要成长心态来克服
