# 双重编码理论
> 语言+视觉=两条记忆通路。一条断了还有另一条。

## 核心
- 语言系统：处理文字/语言信息
- 视觉系统：处理图像/空间信息
- 同时激活两个系统 = 记忆强度翻倍
