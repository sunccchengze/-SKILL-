## 打脸练习示例

### 练习：你的技能库是什么系统？

**预测**：
```
我的技能库是一个检索系统。
用户输入任务→系统匹配技能→返回结果。
```

**实验**：
- 用系统之美分析你的技能库
- 画出技能库的因果回路图

**打脸**：
- 发现：技能库不是静态检索，是动态演化的
- 发现：有增强回路（用得多的技能变得更完善）
- 发现：有平衡回路（不用的技能逐渐过时）
- 发现：技能之间有"力场"（Alexander的概念）

**修正**：
- 技能库是复杂适应系统，不是检索系统
- 需要关注反馈回路，不只是匹配算法
- 写入MEMORY.md
