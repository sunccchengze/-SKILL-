1. 范畴论 - 对象与态射/函子/万物皆范畴
2. 拓扑学 - 连续变形/同胚/不变量
3. 图论 - 节点/边/树/最短路

10. 计算复杂性 - P vs NP/可归约性
11. GEB - 自我指涉/怪圈/涌现
12. 不确定性原理 - Heisenberg
13. 对称性与守恒 - Noether定理
14. 统计力学 - 微观→宏观
15. 混沌理论 - 蝴蝶效应
16. 幂律分布 - 80/20/齐普夫
17. 相变理论 - 临界点
18. 场论 - 连续场/叠加
