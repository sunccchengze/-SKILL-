# 认知负荷理论
> 工作记忆只有~4个组块。超过就崩溃。

## 三类负荷
| 类型 | 来源 | 处理 |
|------|------|------|
| 内在负荷 | 材料本身复杂度 | 分解/分步 |
| 外在负荷 | 不良教学设计 | 消除冗余 |
| 关联负荷 | 促进图式建构 | 增加有益负荷 |

## 你的对照
- 6科并行 = 高内在负荷管理
- 你的HANDOFF文件设计 = 减少外在负荷
- 打脸链路 = 增加关联负荷（有益困难）
