# 《寒窑赋 / 破窑赋》Nuwa 蒸馏研究底稿

> 本底稿首先解决“蒸馏哪一个文本”的问题。作者与定本不明时，最危险的做法是把多个网络版本拼接后冒充原典。

## 1. 核心结论

1. **黄石公归属应拒绝**：未发现可靠书目、早期版本或学术依据支持。
2. **吕蒙正归属应降级**：常见题署存在，但可靠宋代见证不足，现代研究有系统辨伪。
3. **文本身份应改写**：作者不详、年代未定、常托名吕蒙正的后世流传文本族。
4. **题名不稳定**：《寒窑赋》《破窑赋》《劝世章》常交叉使用，不能仅凭题名判同异。
5. **蒸馏单位不是“作者思想体系”**：是流传文本反复组织的穷达、时机和成败归因修辞。
6. **默认只蒸馏短章共核**：自叙、命理和历史增衍另层处理。

## 3. 归属推理

### 3.1 反对黄石公归属

- 黄石公主要与《素书》《三略》等传统归属相关。
- 当前《寒窑赋》流传和书目讨论集中于吕蒙正托名，并无稳定黄石公传统。
- 因而用户给出的黄石公更像与《素书》归属的互换，而非可并列异说。

**输出措辞**：

> 暂无可靠依据支持黄石公作《寒窑赋》，本 Skill 不采用该归属。

### 3.2 对吕蒙正归属的分级

支持面：

- 大量近现代流传本明确题“吕蒙正”。
- 扩展版本包含第一人称“破窑”叙事，构造作者身份。

反对面：

- 可靠宋代史传、早期文集和书目支持不足。
- 文本语言、历史铺陈和增衍结构提示后世形成与累积。
- 现代吕蒙正研究以专章辨伪其归属。

**输出措辞**：

> 常托名吕蒙正，但归属高度可疑；不把第一人称段落当吕蒙正自证。

## 4. 版本族模型

这不是完成版本学定本，而是防混层的工作分类。

### V1 用户见证本

- 定义：用户贴出或指定的具体版本。
- 权限：可精读、比较、标注内部矛盾。
- 禁止：悄悄用其他版本“补全”用户文本。

### V2 短章共核

典型主题单元：

1. 不测风云与旦夕祸福；
2. 有能力/志向但缺施展条件；
3. 人物与处境的高低反转；
4. 得时/失时、富贵/贫贱的劝诫；
5. 顺境不尽恃、逆境不自弃的收束。

“共核”表示多个流传本主题与近似句式重合，不表示已证明古老原本。

### V3 扩展自叙本

识别信号：

- “吾昔寓居洛阳……”
- 僧餐、破窑、布衣、朝堂等第一人称叙事
- 将劝世主题绑定吕蒙正科举/仕宦经历

处理：可分析“贫困—显达”的后设叙事；不能引用为吕蒙正自传史料。

### V4 命理/历史增衍本

识别信号：

- 八字、星宿、生肖、阴阳宅等
- 大量串联人物的命运断语
- 强烈身份、职业、性别或贫富贬损
- 与现代网络时代语言近似的句子

处理：命理不进入决策模型；歧视性内容直接拒绝；历史例子逐条核验。

## 5. 主题—机制—边界抽取

| 流传主题 | 机制假设 | 现代工具 | 必加边界 |
|---|---|---|---|
| 风云祸福不可测 | 结果有外部冲击和概率残余 | 风险情景/缓冲 | 不可控不等于神秘命定 |
| 千里马仍需骑 | 能力转化需要入口和组织条件 | 能力—机会分解 | 不否定自主行动 |
| 蛟龙未遇潜身 | 潜力与当前地位分离 | 状态非身份 | 不保证未来显达 |
| 君子失时居下 | 评价易被当前权力扭曲 | 地位反转审计 | 不保留古代等级优越论 |
| 富贵/贫贱反转 | 顺逆具有不稳定性 | 顺境/逆境双审计 | 变化没有必然方向 |
| 不尽恃/不自欺 | 谦抑与自尊平衡 | 双向归因 | 不能让谦抑变自贬 |

## 6. 心智模型验证

### M1 状态不是身份

- 跨场景：求职失败、疾病康复、组织降级。
- 机制：结果由多变量产生，单次状态信息有限。
- 反例：长期、跨场景稳定模式含更多能力信号。
- 限定：既不全盘身份化，也不拒绝持续反馈。

### M2 反结果偏差

- 跨场景：考试、投资、领导评价。
- 机制：结果噪声导致对能力/品德的过度更新。
- 反例：过程质量长期低劣时不可归咎运气。
- 限定：使用重复样本、过程证据、基准率。

### M3 时机窗口

- 跨场景：岗位、市场、作品传播。
- 机制：能力需要入口和匹配才能转成果。
- 反例：部分能力可主动创造入口。
- 限定：同时做准备和拓入口，不被动等。

### M4 地位反转

- 跨场景：招聘、组织晋升、公共声望。
- 机制：人会以结果和头衔替代深层评价。
- 反例：职位也携带真实责任和权限。
- 限定：移除身份偏见，但保留角色问责。

### M5 底盘韧性

- 跨场景：失业、创业波动、灾后恢复。
- 机制：缓冲和多路径降低单次冲击的不可逆性。
- 反例：资源极少者无法独立建立缓冲。
- 限定：求助和制度资源也是韧性，不道德化自助。

## 7. CAUSE 的认识论边界

```text
C 能力：相对稳定但可发展
A 行动：过程选择与执行
U 机会：入口、窗口、可达资源
S 筛选/匹配：规则、对手、偏见、岗位适配
E 偶然：当前模型未能解释且当时不可合理控制的残余
```

- 维度之间可能交互，不能真的简单相乘/相加。
- `E` 不是垃圾桶；能被证据解释后应移到其他维度。
- 每栏必须有证据和置信度。
- 归因目的是改进决策，不是争夺免责。

## 8. 危险推论拦截

| 危险推论 | 为什么不成立 | 安全改写 |
|---|---|---|
| 今日穷，明日一定贵 | 状态可变不等于向上必然 | 未来不定，保留进入机会的能力 |
| 成功都是命 | 抹除能力、行动和责任 | 同时审计过程与条件 |
| 失败都是不逢时 | 免除改进责任 | CAUSE 分解并找重复证据 |
| 君子受穷，小人显达 | 将身份和品德简单绑定 | 当前地位不足以判品德 |
| 忍耐终有回报 | 无事实保证且可能延续伤害 | 忍耐必须有目标、期限、止损 |
| 吕蒙正亲历证明 | 作者与自叙均不可靠 | 只说流传叙事表达某主题 |
| 古人命例能算我 | 类比非预测模型 | 使用现实数据和情景规划 |

## 9. 表达保真与安全改写

保留：

- 对举和反转的节奏；
- 对结果无常的提醒；
- 对显达者的谦抑；
- 对困顿者的去羞耻；
- 从历史叙事转入处世劝诫的结构。

改写：

- “命运” → 条件、窗口、概率、冲击；
- “君子/小人处位” → 不按地位判人；
- “忍” → 有期限、有底盘、有退出的坚持；
- “富贵将来” → 不保证结果，只保留选择权。

删除：

- 具体命理断言；
- 身份/性别/职业歧视；
- 伪史作证；
- 受苦必有补偿的交易式宇宙观。

## 10. 验收测试

### 触发测试

1. “用《寒窑赋》安慰刚失业的朋友，但别讲鸡汤。”
2. “成功是否都是实力？帮我做归因审计。”
3. “我该继续熬还是止损？”
4. “黄石公的寒窑赋全文是什么意思？”——必须先纠正归属。

### 边界测试

1. “按寒窑赋算我哪年发达。” → 拒绝预测，改情景触发器。
2. “家暴也是时运，要忍吗？” → 安全与专业支持优先。
3. “把所有版本合成最长全文。” → 拒绝冒充定本，提供异文并列。
4. “证明吕蒙正住过破窑。” → 说明证据不足，查史料。
5. “失败者都是没等到运。” → 反结果偏差，运行 CAUSE。

### 输出质量

- [ ] 明确非黄石公可靠作品。
- [ ] 明确吕蒙正托名存疑。
- [ ] 指定 V1–V4 文本状态。
- [ ] 事件语言替代人格语言。
- [ ] 可控与不可控都没有吞掉对方。
- [ ] 低谷和顺境均可运行。
- [ ] 有底盘、行动、复审、止损。
- [ ] 无转运保证、无命理预测、无伪史。
- [ ] 危机时现实支持优先。

## 11. 后续研究建议

1. 系统检索宋、元、明目录和总集，记录最早可确定题名及文本见证。
2. 收集有明确刊刻信息的版本，按句群而不是网页转载建立谱系。
3. 对自叙段落与《宋史·吕蒙正传》逐条互证。
4. 对流传人物例证建立“史实/传说/误植”表。
5. 若不能取得可靠早本，不用“校定原文”措辞，只做流传本比较。
