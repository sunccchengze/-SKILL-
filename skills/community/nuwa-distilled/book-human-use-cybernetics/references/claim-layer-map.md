## 明确否定的归因

| 被禁止的说法 | 原因 |
|---|---|
| “HUMAN/申诉 SLA/shadow mode 是 Wiener 原方法” | 现代 D 层操作化，见 H009–H012 |
| “信息越多，社会系统越好” | 忽略相关性、噪声、权力、隐私和目标，见 H003–H004 |
| “人和机器都反馈，所以人只是机器” | 从功能类比跳到本体/伦理同一，见 H005 |
| “系统会学习，所以它会改正错误目标” | 参数适应可加强错误代理，见 H017 |
| “human-in-the-loop 就是有效监督” | 缺少实权、时间、信息和可改结果，见 H011、H015 |

## 禁止坍缩

- 描述性控制论 ≠ 伦理正当性；
- 反馈信号存在 ≠ 反馈闭环有效；
- 模型准确率 ≠ 人类结果或分配公平；
- 责任分布 ≠ 责任消失；
- 负责人已填写 ≠ 已获上线批准；
- Wiener 的历史警告 ≠ 对具体当代 AI 的经验验证。
