# 可执行治理模板

这些是 D 层审计制品，不是 Wiener 原书表格，也不是法律/部署批准。未知项写 `未知/待核`；高风险不得用占位符执行。

## 0. 高风险治理门

```markdown
- 系统 / 决策 / 风险等级：
- accountable owner（有暂停/退役权）：
- applicable rule（法域、劳动、隐私、安全、领域）：
- appeal path（可达、时限、可改结果、反报复）：
- rollback trigger（分母/窗口/阈值）：
- 立即保护/通知/补救义务：
- 输出用途：治理工作表，不是 deployment approval
```
