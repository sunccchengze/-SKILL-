# Research Pass 02 — 财富模型的 Naval 原始/近原始材料

## 目标

从 `nav.al` 回溯 specific knowledge、accountability、ownership、leverage、judgment 与 “productize yourself”，并把描述性经验、规范建议和结果承诺分开。

## 原始材料结构

`How to Get Rich` 及其拆分页面把财富路径表示为：发展难以替代的特定知识、在自身判断上承担公开责任、保留所有权上行、使用劳动力/资本/代码/媒体杠杆、与可信的人做长期游戏。`Judgment` 强调杠杆会放大判断质量；`Productize Yourself` 将独特能力与可复制输出连接。

## 可保留洞见

1. 特定知识可被视为“持续好奇 + 实际反馈 + 难标准化的组合能力”假设，适合用小项目探索，而非人格测试决定。
2. 代码和媒体确实具有低边际复制成本，能让单人作品获得远超一对一劳动的触达。
3. 公开署名、兑现承诺与 ownership 可以对齐部分上行和责任；长期关系能降低重复交易摩擦。
4. 判断在高杠杆环境中更重要，因此放大前应先校准、限制下行并保留复核。

## 不能保留为定律

- “无运气致富”不能理解为排除随机性、网络和时代条件；标题/修辞不是识别策略。
- permissionless 不代表没有设备、时间、教育、分发、语言、资本、合约和照护门槛。
- accountability 不授权无限个人担责，也不允许把外部性转嫁给员工、用户或家庭。
- productize yourself 不要求身份、关系、隐私和休息全部变现。

## 纳入产物

- A-NAV-01 至 A-NAV-04；
- NAVAL-OPTION 的 Name / Verify / Allocate；
- 来源四格与“同目标替代路径”；
- 低成本可逆试验优先。

## 未解决
