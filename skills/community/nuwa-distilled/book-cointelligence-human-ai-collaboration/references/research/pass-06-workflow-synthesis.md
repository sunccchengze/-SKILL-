# Pass 06｜工作流综合与验证

CO-LAB：Compliance → Name outcome/goal → human baseline → decompose → route mode → specify role → generate alternatives → verify → unaided check → compare/log → decide/disclose。

路由依据不是“喜欢哪种风格”，而是重要性、可验证性、隐私、学习关键性和失败后果。测试问题：

- 高重要、低可验证的子任务是否被路由为专家治理？
- 学习关键步骤是否先有人类尝试并安排撤 AI 测试？
- 输出是否声明角色模拟不等于人格/资质？
- 是否记录模型、日期、提示、产物和总验证时间？
- capability ledger 是否只对具体模型+日期+任务有效？
- 最终是否有具名的人类责任人、披露与停止条件？

若任何高风险项缺失，计划不得升级为部署。
