# 《系统之美》系统干预 Skill

> **定位**：把 Meadows 的系统语言变成“观察—建模—质疑—小步干预—回传证据”的工作台。它不是复杂感的装饰，也不把一张漂亮的回路图冒充已验证的因果模型。

## 一、何时使用

适合：反复出现却无法靠一次修补解决的问题；库存积压或枯竭；政策反弹；跨团队激励冲突；增长遇限；目标漂移；信息延迟；公地、升级竞争、转嫁负担等结构。

不适合直接使用：

- 明确的单点故障且修复路径已知；
- 火灾、急症、暴力等必须先执行应急协议的情境；
- 试图用“系统导致”抹去具体行为者的法律或伦理责任；
- 没有受影响群体参与，却要替他们定义福祉、目标与可接受代价；
- 只有横截面相关或主观连线，却要求给出确定因果和不可逆政策。

## 二、来源分层与证据状态

| 层 | 内容 | 合格说法 |
|---|---|---|
| A. BOOK/作者框架 | 系统的要素—连接—功能，库存/流量，强化/平衡反馈，延迟、韧性、陷阱、杠杆点与“与系统共舞” | “Meadows 在书/论文中提出……” |
| B. 独立方法证据 | 因果图透明度、模型验证、因果识别、实施与评估方法 | “独立方法文献要求……” |
| C. 批评/限制 | 定性 CLD 不能单独识别因果；中心性可能制造错误杠杆判断；边界与目标含权力选择 | 明示适用条件和未知 |
| D. Skill 综合 | SYSTEM-TRACE 九步法、连接证据表、杠杆假设卡、可逆实验和证据回传 | “本 Skill 创建……” |

每条因果连接必须标为且只能标为以下之一：

1. **stakeholder-hypothesis｜利益相关者假设**；
2. **literature-supported-link｜文献支持的连接**；
3. **measured-association｜实测关联**；
4. **identified-causal-effect｜已识别因果效应**。

后两者也不等价：相关不是因果；“已识别”仍需记录设计、样本、估计对象和外推边界。

## 三、七个核心心智模型

### 模型1：库存是系统记忆，流量才直接改变库存

- 库存是在某一时点积累的数量；流入与流出是单位时间的变化率。
- 先写守恒关系：`库存下一期 = 当前库存 + 流入 - 流出`，再讨论故事。
- 同一库存可同时受多个流影响；只盯流入常漏掉泄漏、流失和淘汰。
- **局限/失效**：信任、能力、合法性等抽象库存若不可操作化，会制造伪精确；应写代理指标和不确定性。

### 模型2：反馈解释模式，不替代证据

- 强化回路放大变化，平衡回路向目标/边界调整；正负表示方向，不表示好坏。
- 回路要闭合、方向一致、变量可变化，并写延迟。
- **局限/失效**：CLD 表示建模者相信的因果结构；没有设计或数据时，它只是可批评的假设。

### 模型3：看行为随时间，不被事件快照绑架

- 至少画出结果和关键库存的历史趋势、转折点、波动与期望轨迹。
- 区分事件、行为模式、结构和心智模型；越往下越需要更强证据与参与。
- **局限/失效**：趋势图可显示共变和延迟，却不能自动给出机制；制度断点也可能破坏历史外推。

### 模型4：延迟会制造超调、振荡与误归因

- 感知、决定、交付、生物/组织响应都有延迟；干预者可能在效果到来前反复加码。
- 写清“多久可见早期信号、多久可见结果、何时不应继续加码”。
- **局限/失效**：延迟长度若完全未知，应先测量，不凭直觉设控制频率。

### 模型5：韧性、自组织与层级不是低效同义词

- 冗余、缓冲、多样性和自治可能牺牲短期效率，却提高吸收冲击和适应能力。
- 层级要服务子系统，也要允许子系统维持自身功能。
- **局限/失效**：把所有冗余都叫韧性会保护浪费；必须说明抵御什么冲击、代价由谁承担。

### 模型6：系统陷阱是结构假设，不是标签诊断

- 政策阻力、目标侵蚀、升级、公地悲剧、成功者成功、转嫁负担、规则规避和追错目标都是候选结构。
- 必须列出可观察征象、竞争解释和反证。
- **局限/失效**：用熟悉原型套问题会忽略历史、文化与权力；原型只负责提问。

### 模型7：杠杆越深，越难实施，也越需合法性

- 参数、缓冲、结构、延迟、反馈、信息、规则、自组织、目标、范式可作一组探索层级。
- Meadows 明确把杠杆顺序称为仍在发展的启发，不是效果排行榜。
- **局限/失效**：深层改变不保证更好；目标/范式干预可能不可逆、被少数人夺取。图中心性不得直接决定杠杆优先级。

## 四、主工作流：SYSTEM-TRACE 九步法

这是 **本 Skill 的 D 层现代综合**，不是书中原有章节。

### 0. Stop and scope｜先应急，再划边界

- 是否存在必须立即处置的伤害？有则先走应急/专业协议。
- 写清焦点问题、时间范围、地理/组织边界、系统外部输入以及为什么这样划界。
- 列出边界遗漏者；边界是分析选择，不是世界天然边界。

### 1. Track behavior over time｜追踪行为趋势

选择 1 个结果、2–5 个候选库存，记录至少三个时间点、转折、周期和数据缺口。把实际、期望和预测分线；预测必须标方法和不确定性。

### 2. Enumerate stakeholders and purposes｜列利益相关者与多重目标

分别问：谁受益、谁付费、谁承担风险、谁有否决权、谁没有数据表达权？“系统目的”优先从持续行为和奖励结构推断，但标为假设并让相关方质疑。

### 3. Specify stocks, flows and measures｜写库存、流量和测量

每个库存写：单位、代理指标、流入、流出、数据来源、更新频率。若无法写单位，说明它是定性构念而非物理库存。

### 4. Expose feedback and delays｜展开连接、反馈与延迟

每条边记录：起点、终点、极性、机制、延迟、证据状态、来源、竞争解释、反证。禁止只画箭头不建连接表。

### 5. Test rival structures｜与竞争结构对打

至少写两个可解释同一趋势的替代模型；寻找会让它们做出不同预测的观测。问：是否是共同原因、选择偏差、反向因果、制度变化或测量改变？

### 6. Examine traps and distribution｜检查陷阱、权力与分配

原型只作检查单。记录收益/伤害在群体和时间上的分布，尤其是不可逆损失、退出权、申诉权与数据盲区。

### 7. Generate leverage hypotheses｜生成杠杆假设

每个候选必须写：目标机制、证据级别、受影响群体、前置能力、副作用、延迟、可逆性和停止条件。参数、小结构和深层规则可以组合；不按“深”自动排序。

### 8. Run a bounded intervention and return evidence｜小步干预并回传证据

优先可逆、局部、时限明确的试点；干预前记录基线，设过程/结果/分配/副作用指标，尽可能用对照、分期、时间序列或其他识别设计。到期选择：扩展、修改、停止或补证据，并更新连接状态。

## 五、证据门与因果纪律

### 连接升级规则

- 利益相关者说法 → `stakeholder-hypothesis`；
- 多篇相关理论/研究支持机制 → `literature-supported-link`；
- 本地时间/横截面数据共变 → `measured-association`；
- 可信实验或准实验识别了明确估计对象 → `identified-causal-effect`。

状态不能凭投票升级。每次升级都保留旧记录、设计和外推限制。

### 禁止的捷径

- “A 与 B 同时上升，所以 A→B”；
- “节点度数最高，所以它是最佳杠杆点”；
- “回路是强化的，所以一定要切断”；
- “系统有目的，所以存在一个统一意志”；
- “复杂系统不可预测，所以无需评估”；
- “一切相连”，却不声明边界。

## 六、输出契约

每次完整回答至少包含：

1. 焦点问题、时限、边界与遗漏；
2. 利益相关者和相互冲突的目标；
3. 行为随时间表；
4. 库存—流量账本；
5. 带四级证据状态的连接表；
6. 回路/延迟作为假设；
7. 两个竞争解释及区分观测；
8. 2–4 个杠杆假设，不按中心性排序；
9. 可逆试点、停止条件、分配指标与证据回传计划；
10. 作者框架、独立证据、批评与 Skill 综合分栏。

CLI：

```bash
python3 scripts/map_system.py \
  --problem "博士生项目延期反复发生" --horizon "12个月" \
  --stakeholder "博士生" --stakeholder "导师" \
  --outcome "按质量门完成里程碑" \
  --link '返工量|+|待办库存|stakeholder-hypothesis|组会访谈' \
  --link '待办库存|+|等待时间|measured-association|2025工单时间序列' \
  --output system-map.md
```

## 七、表达DNA

- **句式**：先写证据/假设与边界，再写动作；**词汇**：优先使用本 Skill 的工作流术语；**语气**：校准而不绝对化；**引用**：关键声明保留来源层和日期。

- **句式**：先写边界和变量，再写机制；少用“根因”单数。
- **词汇**：库存、流量、反馈、延迟、证据状态、竞争解释、可逆性。
- **语气**：好奇但不神秘；明确说“这条箭头目前只是利益相关者假设”。
- **节奏**：事实 → 图假设 → 反证 → 干预 → 监测。
- **确定性**：用级别和设计表达，不用“系统必然”。
- **引用**：作者框架归 Meadows；因果识别与 CLD 限制归独立方法来源。

## 八、内在张力

> 下列每项都是必须保留、不能用口号消解的工作流张力。

- **整体视角 vs 可行动边界**：边界太窄漏掉外部性，太宽则无人能行动。
- **深层杠杆 vs 民主合法性**：目标和规则或许影响大，却最不能由分析者单方面改写。
- **效率 vs 韧性**：去冗余提高短期效率，也可能放大冲击。
- **模型简洁 vs 现实多元**：图要可读，但删去的群体与机制可能正是问题核心。

## 九、诚实边界

- 本 Skill 不读取或复制整本受版权保护图书；书框架来自必要概念、官方材料与公开作者文章。
- 定性系统图和原型不能单独证明因果、量化效应或给出可靠预测。
- 杠杆层级是思考启发，不是经验证的通用效果排名；中心性不能替代机制与识别。
- 系统模型永远受边界、数据、参与者与建模者价值影响，必须保留异议和版本。
- 高风险政策、临床、安全或权益决定需领域专家、受影响群体和正式治理流程。
