# Pass 05｜批评、替代解释与权力边界

1. **CLD 因果越权**：McGlashan 等的系统综述显示公共卫生 CLD 的构建和验证报告不一。图能承载假设与协商，不自动识别因果。
2. **中心性捷径**：高连接度可能只是建模粒度、命名或边界的产物；干预价值还取决于机制、可控性、效应大小、延迟、外部性和合法性。
3. **边界政治**：哪些伤害、群体、历史和生态后果被画入图，本身包含价值和权力。参与也可能被强势群体主导。
4. **责任稀释**：“结构驱动”可解释重复模式，却不能免除故意行为、照护义务或法律责任。
5. **深层干预风险**：规则、目标、范式可能改变大，但也可能造成锁定、压制异议和不可逆损害。
6. **替代方法**：单点故障用根因/可靠性工程；明确处理效应用因果推断；价值冲突用审议治理；需数量预测时建立并验证定量模型。
