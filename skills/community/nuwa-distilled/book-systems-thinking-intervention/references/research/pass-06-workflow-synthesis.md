# Pass 06｜工作流综合与验证问题

SYSTEM-TRACE 把书框架与独立方法拼为九步：Stop/scope → Track → Enumerate → Specify → Expose → Test rivals → Examine distribution → Generate leverage hypotheses → Run bounded intervention。

设计原则：

- 先应急和划界，避免系统分析延误处置；
- 行为、库存、连接分开记录；
- 四级证据状态阻止“箭头漂白”；
- 至少两个竞争结构和区分观测；
- 杠杆按机制、证据、权益、可逆性筛选，不按图中心性；
- 每个试点有基线、停止条件、分配/副作用指标和连接升级规则。

验证问题：输出是否含边界遗漏？是否保留相关/因果区别？是否给出反证？是否让受影响群体有异议/退出/申诉通道？干预是否可逆？证据能否回流更新地图？任一答案为否，应停在假设阶段。
