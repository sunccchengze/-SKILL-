# book-systems-thinking-intervention

Meadows《系统之美》深层系统干预包：将库存—流量、反馈、延迟、韧性、陷阱与杠杆点转为可质疑、可逆、可回传证据的工作流。

```bash
python3 scripts/map_system.py --problem "反复延期" --outcome "可靠完成" --horizon "12个月" --stakeholder "执行者"
python3 -m unittest discover -s tests -v
```

核心纪律：CLD 是待检验模型，不是因果证明；相关不等于因果；图中心性不等于杠杆优先级。
