# 声明分层地图

本表是输出时的最小追踪单位。**A** 为《第五项修炼》主张，**B** 为明确的方法谱系，**C** 为后续研究/批评，**D** 为本 Skill 的操作化。`否` 表示明确禁止的归因。

| ID | 可使用的声明 | 层 | 主要来源 | 证据与使用限制 |
|---|---|---|---|---|
| F001 | 五项修炼是个人掌握、心智模型、共同愿景、团队学习和系统思考 | A | FD-01, FD-02 | 系统思考是整合者；不是顺序成熟度清单 |
| F002 | 学习型组织旨在持续扩大共同创造期望结果的能力 | A | FD-01 | 规范性定义，不是组织绩效保证 |
| F003 | 只盯事件会遮蔽较长期的模式与生成结构 | A | FD-01 | 紧急事件仍须立即处置；结构需独立证据 |
| F004 | 决策后果超出岗位、地点或复盘周期时，直接经验不足以支持学习 | A | FD-01 | 具体“学习视野”需按真实时滞和边界界定 |

## 明确否定的归因

| 被禁止的说法 | 原因 |
|---|---|
| “Senge 发明了系统动力学、反馈或所有因果环工具” | 谱系错误，见 F006–F008 |
| “LOOPS 是原书方法” | LOOPS 为 D 层综合，见 F009 |
| “画出回路就证明了因果/预测了结果” | 制品层级与证据越界，见 F007、F010、F015 |
| “共同愿景意味着所有人应同意管理层目标” | 把承诺坍缩为服从，且忽略权力 |
| “系统造成，所以无人负责” | 结构解释不取消责任，见 F019、F022 |

## 不能互相替代

- 系统结构解释 ≠ 法律、伦理或专业责任判断；
- 共同愿景声明 ≠ 成员真实承诺；
- 定性回路 ≠ 定量系统动力学模型；
- 基模相似 ≠ 将出现同样结果；
- 参与式会议 ≠ 已公平纳入受影响者；
- 复盘会议 ≠ 已改变未来规则、资源或行为。
