# 《第五项修炼》学习系统 Skill

> **定位**：把“看全局”变成可审计的跨期理论：先看行为如何随时间变化，再画反馈、时滞、心智模型和权力，最后用小干预检验。不是给每个问题贴一个基模名称。

## 一、何时使用

适合：

- 同类故障反复、组织总在救火；
- 一个部门完成 KPI，却把成本推给其他团队/未来；
- 越努力结果越差，或短期变好、长期恶化；
- 需求增长后质量、能力或信任遇到上限；
- 会议争论停在事件和归责，缺少共同因果理论；
- 共同愿景、团队学习和一线反馈无法进入决策。

不适合单独使用：

- 紧急安全事故、违法、骚扰、歧视、财务造假或明确专业失误：先保护人、留证、报告和履责；
- 只有一个独立、确定、可复现的局部故障：先用直接根因分析；
- 要从定性因果图计算概率、效应量或预测日期；
- 管理层想借“共同愿景”要求员工认同既定结论。

## 三、默认认识论

1. **事件不是模式。** 单次事故先处理，但结构判断至少需要时间范围和重复证据。
2. **图是理论，不是真相。** 每条箭头都要写证据、假设、时滞和可反驳条件。
3. **结构不取消能动性。** 系统塑造选择，不等于任何个人/机构不承担责任。
4. **边界决定结论。** 图外的人、成本和时间可能让“成功”翻转。
5. **基模只负责提问。** 匹配名称不证明案例属于该基模。
6. **学习要改变未来行动。** 只有复盘总结、没有规则/资源/行为更新，不算闭环学习。

## 四、七个核心心智模型

### M1 事件—模式—结构

- 事件：这次发生了什么；
- 模式：变量在给定时间内怎样变化；
- 结构：哪些反馈、时滞、规则和资源持续生成该模式；
- 心智模型：参与者如何解释并维持结构。

规则：至少画一张行为随时间图，再讨论结构。失败：从一次案例跳到宏大系统解释。

### M2 强化与平衡反馈

- 强化回路放大同方向变化，可增长也可崩塌；
- 平衡回路围绕目标/约束抵消变化；
- “正/负”指回路性质，不表示好坏。

规则：闭环才是反馈；一条 A→B 箭头不是回路。变量名用可增减量，不用“提高/降低”句子。

### M3 时滞与学习视野

行动到可见结果之间的延迟会引发过度纠偏；重要后果超出职位、项目或复盘周期时，人无法仅凭直接经验学习。

规则：每条关键关系问“多久显现、多久可观察、多久会被制度记住？”

### M4 系统基模作为诊断镜片

优先使用少量：

- **舍本逐末（Shifting the Burden）**：症状解法削弱根本能力；
- **增长上限（Limits to Growth/Success）**：强化增长遇到约束；
- **饮鸩止渴（Fixes That Fail）**：短期修复产生延迟副作用；
- **目标侵蚀（Drifting Goals）**：通过降低标准消除差距；
- **强者愈强（Success to the Successful）**：资源倾斜自我强化。

规则：写“像……，待核验”；必须给不匹配证据。

### M5 心智模型：把隐含假设放上桌

人的假设影响注意、测量和行动。工作方法：区分观察、解释、推论和主张；邀请参与者写“什么证据会让我改图”。

失败：把“心智模型”当批评他人偏见的工具，而不审查自己的图。

### M6 共同愿景与个人掌握

共同愿景应形成参与和承诺，不是把管理层目标换成鼓舞口号；个人掌握是持续澄清愿景与现实张力，不是无边界自我优化。

规则：成员可以影响、质疑和不认同；愿景必须连接资源、权利和取舍。

### M7 团队学习：从主张竞争到共同检验

团队学习需要对话、探询、暴露假设和共同试验。会议产出不是一致意见，而是：竞争解释、待补证据、负责人与更新日期。

失败：权力差异让一线人员无法反驳，表面共识不等于共同学习。

**模型的共同局限**：这些模型都会在边界过窄、变量不可测、参与者权力不对等或时间范围错误时失效；任何一个模型都不能只凭名称证明因果。若无法写出反驳条件，就把它降级为讨论提示。

## 五、主工作流：LOOPS 六步法

这是 **本 Skill 创建的现代综合**。

### 0. Limit harm and scope｜先处理伤害与范围

- 紧急安全/违法先履责，不等系统图；
- 固定问题、时间范围、系统边界和决策权限；
- 分开已知事实、解释和未知。

### L. Locate the recurring outcome｜定位重复结果

把问题写成可观察变量，不写人格：

- 差：“团队不重视质量”；
- 好：“过去 12 周，发布频率上升后，返工工时在约两周后持续增加”。

定义一项结果、一个时间轴和至少一个受影响群体。

### O. Observe behavior over time｜观察行为随时间

为 3–6 个关键变量画过去—现在—期望趋势。标事件、政策变化、数据缺口。只有单点数据时，明确不能推断模式。

### O. Outline loops, delays and boundary｜画回路、时滞与边界

- 变量用名词/可增减量；
- 箭头标同向/反向、证据等级和时滞；
- 闭环标 R（强化）或 B（平衡）；
- 同时写一个竞争回路和一个图外变量；
- 不确定箭头用虚线/“待核”。

### P. Probe archetypes, mental models and power｜探查基模、假设与权力

- 哪个基模像当前结构？哪里不像？
- 哪个短期解法在削弱长期能力？
- 谁定义目标和指标，谁承受延迟成本？
- 哪些人知道现实却不能改变图？
- 什么证据会推翻当前解释？

共同愿景只在参与者可影响目标时讨论。

### S. Select a leverage experiment and learn｜选择小干预并学习

输出一个 2–6 周、有限范围、可逆的干预：

- 改一个结构变量，而非同时重组一切；
- 写预期的短/长期变化和可能副作用；
- 定基线、领先/滞后指标、复盘窗口；
- 写继续、扩大、调整、停止条件；
- 复盘时保留原图并记录哪条箭头被支持/削弱。

## 六、因果环最小语法

```text
变量 A --同向--> 变量 B
变量 B --反向--> 变量 C [delay: 2 weeks]
变量 C --同向--> 变量 A
```

- 同向：其他条件不变时，A 增使 B 相对增加（或 A 减使 B 相对减少）；
- 反向：A 增使 B 相对减少；
- 回路符号由所有关系组合决定；
- “其他条件不变”在复杂系统中是建模假设，必须允许现实反驳。

## 八、快速决策规则

- 没有时间轴，不宣布结构模式。
- 单箭头不是反馈，模板匹配不是诊断。
- 每条关键箭头都要证据标签和反驳条件。
- 图至少留一个竞争解释和一个图外变量。
- 局部指标变好时，检查成本是否被推到别处或未来。
- 同一短期修复重复两次，查它是否在削弱根本能力。
- “共同愿景”若不能被影响，只是服从话术。
- 小干预先于大重组；高不可逆事项先专业治理。

## 九、常见失败模式

| 失败 | 表现 | 修复 |
|---|---|---|
| 基模星座 | 一个问题套五个基模 | 选一个主假设并写不匹配点 |
| 箭头即因果 | 开会画图就宣称根因 | 证据标签、竞争图、现实测试 |
| 无时间系统图 | 只有静态方框 | 行为随时间 + 时滞 |
| 系统洗责 | “结构如此，没人有错” | 分开结构解释与责任/伦理 |
| 边界套利 | 部门成功、组织受损 | 标外部性与受影响者 |
| 共识强迫 | 既定 KPI 被包装成愿景 | 允许影响、异议和退出 |
| 复盘无学习 | 写总结不改规则 | 指定规则/资源/行为更新 |
| 杠杆点神话 | 声称一招改变复杂系统 | 小试验、监测副作用、可回滚 |

## 十、表达DNA

- **句式**：先描述事实、时间曲线和边界，再解释结构；
- **词汇**：多用“变量、模式、结构、回路、时滞、边界、待核、竞争解释”；
- **语气与确定性**：中性、探询；图和基模均用假设语气，不模仿 Senge；
- **引用**：原书、方法谱系和 Skill 综合分层标注；
- **节奏**：每轮只推进一个主回路和一个小干预；
- 每个建议带范围、周期、指标和停止条件，并明确谁有权定义目标和改变结构。

## 十一、内在张力

- **整体 ↔ 可行动范围**：边界过窄会局部优化，过宽会无法行动；
- **共同愿景 ↔ 合法异议**：共享方向能协调，也可能被权力制造；
- **结构 ↔ 责任**：系统解释行为，不自动豁免行为者；
- **长期学习 ↔ 紧急处置**：先止血，但不能永远只止血；
- **基模复用 ↔ 案例独特性**：模板加快识别，也会制造确认偏误。

## 十二、诚实边界

- 本 Skill 不是 Senge 本人、原书替代品或系统动力学课程；
- 定性因果环图不能给出效应量、概率或精确预测；
- 五项修炼和学习型组织是管理框架，不是所有行业均已验证的因果定律；
- LOOPS 是本 Skill 综合，未作为标准量表验证；
- 真实组织改变受权力、资源、劳动关系、法规和历史影响；
- 安全、违法和专业失误不能因“系统性”而延迟处置或取消问责。

## 十四、CLI 与产物契约

`python3 scripts/map_learning_system.py --help` 查看完整契约。最低输入为非空 problem/horizon、2–8 个唯一 variable 与 1–8 个唯一 assumption；可重复补充 delay、evidence、stakeholder。`--format markdown|json` 从同一 canonical artifact 确定性渲染，`--output` 写文件，否则输出 stdout。

高风险模式额外要求 `--owner` 与 `--stop-condition`，成功状态也固定为 `analysis_only`。空白、重复、数量越界和缺少高风险字段必须以退出码 2 受控失败；用户文本只作为数据并在 Markdown 表格中转义。CLI 的 claim/source provenance 必须与 `F001–F024` 地图和 source ledger 对齐，不把 D 层工作流冒充原书。

## 十五、最终自检

- [ ] 问题有可观察变量、时间范围和边界吗？
- [ ] 先处理了安全、违法和明确责任事项吗？
- [ ] 行为随时间而非单次事件有证据吗？
- [ ] 回路闭合，箭头有证据、时滞与反驳条件吗？
- [ ] 至少有一个竞争解释和图外变量吗？
- [ ] 基模写成“像、待核”，没有硬套吗？
- [ ] 权力、异议、外部性和责任没有被“系统”遮蔽吗？
- [ ] 干预小、可逆、可测，并有停止与复盘条件吗？
