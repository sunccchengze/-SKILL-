# 《原则》可演化决策系统 Skill

> **定位**：把《原则》从数百条箴言压缩成一个能留下预测、异议、权利边界和更新证据的决策系统。它借 Dalio 的镜片看问题，但不扮演 Dalio，不复制 Bridgewater，不把财富、权威或算法当作真理代理。

## 一、何时使用

适合：

- 同类决策反复出现，但每次都从零争论；
- 一个错误复盘后只有“下次注意”，没有可触发的规则；
- 团队把事实、解释、目标和方案混在同一场争论中；
- 需要在专家意见、负责人判断、投票和算法之间说明决策权；
- 想实践五步过程：目标 → 问题 → 诊断 → 设计 → 执行；
- 想找最有相关记录且真正反对自己的观点，而不是找背书；
- 想把一个原则写成可预测、可例外、可推翻、可版本化的决策规则；
- 想审计“透明”“idea meritocracy”“人才画像”是否正在越界。

不适合单独使用：

- 紧急安全、违法、骚扰、歧视、报复、泄密、临床危机或财务控制失效：先保护人、留证、报告并履行专业/法律义务；
- 需要证券、投资、税务、法律、医疗或心理诊断的个案结论；
- 用 personality / dots / believability 直接决定招聘、晋升、薪酬、转岗或解雇；
- 用“极端透明”要求公开受害者、举报者、病历、特权沟通或个人隐私；
- 用 Bridgewater 的商业成功证明其文化机制普适有效；
- 要算法替负责人作不可申诉的高影响决定。

## 三、认识论合同

1. **原则是待检验的压缩，不是自然定律。** 它应该减少重复思考，但必须保留触发边界、例外与退役条件（P002、P030）。
2. **“现实”不是领导人的观点。** 观察、来源、解释、未知和目标分栏；强势措辞不能升级证据（P003、P031）。
3. **好结果不等于好过程，坏结果也不自动证明过程坏。** 决策质量看事前可得信息、规则和校准；结果另记运气和外部变化。
4. **任务可靠性不等于人的价值。** 只在相似、可结算任务上记录带日期的校准；不生成 global believability（P023–P025、P032）。
5. **公开逻辑，不裸露人。** 透明度按目的、必要性、比例性和权利分配；反馈、评价、调查和举报使用不同访问边界（P021–P022、P034）。
6. **异议要能改变结果。** “大家都可说”若没有无报复、回应义务、独立升级和领导者被覆盖记录，只是仪式（P020、P022、P035）。
7. **算法保留设计者的价值选择。** 编码让规则一致和可审计，也会规模化错误；需要 owner、版本、监测、override、appeal 和 decommission（P015、P033、P036）。
8. **分析输出不是行动许可。** 高风险字段齐全只允许形成治理审查材料，不表示证据真实、合法、公平或可部署。

## 四、六个核心心智模型（按 Nvwa 三重验证）

### M1 原则是“经验 → 规则 → 预测 → 结果 → 修订”的编译循环

- **镜片**：不要只记故事，要抽取未来遇到相似情境时会触发的判断规则。
- **跨域复现**：作者从市场错误扩展到生活决策、组织管理与工具协议（P002、P011、P015）。
- **生成力**：面对新问题会问“这类情境重复吗？规则是什么？下次如何自动提醒？”
- **排他性**：独特处不只是写格言，而是主张把规则系统化甚至编码，并以结果更新。
- **运行规则**：原则卡必须包含 `trigger / action / prediction / exception / falsifier / version`。
- **失败条件**：无法说清适用情境，或任何结果都可事后解释，则它只是口号。

### M2 超现实主义是目标—现实差距的反馈控制，不是冷酷许可

- **镜片**：先明确真正目标，再尽可能准确理解当前现实和约束，差距产生问题定义。
- **跨域复现**：生活目标、市场判断、组织输出都用“想要什么—真实是什么—怎么办”的结构（P003、P006、P009）。
- **生成力**：新决策先分开愿望、观测、解释与不可控约束。
- **排他性**：与“原则编译”和机器类比结合，形成强烈的反馈工程视角。
- **运行规则**：每个“现实”条目给来源、日期、版本、支持/不支持；至少一项未知可能改变选择。
- **失败条件**：管理者把自己的解释叫“现实”，或以“现实主义”压低权利、价值和长期后果。

### M3 五步个人演化：目标 → 问题 → 诊断 → 设计 → 执行

- **镜片**：不同认知任务分步完成，避免看到问题就抢答方案（P005）。
- **跨域复现**：作者用于个人追求，也用于组织机器诊断和持续改进。
- **生成力**：对任何“怎么办”先问目标是否冲突、问题是否可观察、诊断是否有竞争解释。
- **排他性**：固定五步顺序和反复循环是全书最具辨识度的执行骨架之一。
- **运行规则**：目标写取舍；问题写差距；诊断至少两种机制；设计连接机制；任务写 owner/资源/日期。
- **失败条件**：把人的固定特质当根因，或在不确定诊断上直接做不可逆组织变更。

### M4 Radical open-mindedness：把“我可能错”变成寻找反对证据的协议

- **镜片**：自知盲点不足以纠偏，要找相关经验强且不同意自己的人，先学习再决定（P006、P008）。
- **跨域复现**：个人自我校正、投资判断、管理争议和 idea meritocracy 均依赖此动作。
- **生成力**：新问题会主动找最强替代方案、反证和什么会改变自己。
- **排他性**：不仅“听取意见”，而是把反对者、角色（教师/学生/同侪）和争议处理程序系统化。
- **运行规则**：steelman 对手；写原始置信度；记录更新幅度和未更新原因。
- **失败条件**：只邀请可控反对者，或者听完不记录、不回应、不允许升级。

### M5 Believability-weighted idea meritocracy：相关记录挑战权威，但不替代治理

- **镜片**：意见不因人人平等而同样可靠，也不因职位高而更真；关键是与任务相关的可核记录和推理（P012–P014）。
- **跨域复现**：作者把它用于市场判断、会议分歧、职责与组织决策。
- **生成力**：新争议会问“谁在同类问题上有可结算记录？错误是否独立？谁承担后果？”
- **排他性**：显式计算/显示等权与加权结果并与 Responsible Party 并置，是 Dalio 体系的高辨识组合。
- **运行规则**：先展示未加权输入；权重仅基于同域、带日期、足够样本、可比较结果；记录 owner 覆盖及理由。
- **失败条件**：用人格类型、表达风格、同事受欢迎度、地位或旧总分做权重；被评分者不能检查和纠正。

### M6 组织/人生作为可重构机器：从事件上升到设计层

- **镜片**：结果是人员、文化、流程、指标、工具与环境共同生成；管理者既在机器中，也要退一步审视机器（P009、P015）。
- **跨域复现**：作者从投资算法扩展到生活习惯、组织流程和治理工具。
- **生成力**：面对重复失败，不只要求更努力，而是检查输入、接口、激励、控制和反馈。
- **排他性**：工程化、指标化和算法化人类判断的力度构成其独特视角。
- **运行规则**：只把流程视为机器；人的权利、意义、照护、异议和不可量化贡献作为硬约束而非噪声。
- **失败条件**：把人当可替换零件，以总目标合理化监控、歧视、羞辱或集体权利侵害。

### 三重验证结果

| 模型 | 跨域复现 | 生成力 | 排他性 | 结果 |
|---|---|---|---|---|
| M1 原则编译循环 | 市场/生活/工作/工具 | 生成可触发规则 | 规则化并编码 | 保留为核心模型 |
| M2 目标—现实反馈 | 生活/投资/组织 | 生成现实账本 | 与超现实/机器观组合 | 保留为核心模型 |
| M3 五步演化 | 个人/组织 | 生成顺序诊断 | 固定五步循环 | 保留为核心模型 |
| M4 开放心态协议 | 自省/判断/争议 | 生成反证搜索 | 找可信反对者 | 保留为核心模型 |
| M5 可信度加权治理 | 预测/会议/职责 | 生成权重与 owner 问题 | 等权+加权+RP 组合 | 保留但强治理限定 |
| M6 可重构机器 | 人生/投资/组织 | 生成设计层检查 | 强系统化/算法化 | 保留但人权硬约束 |

“诚实”“努力”“有目标”等只通过部分验证，降级为启发式，不冒充独有心智模型。

## 五、十条决策启发式

| 启发式 | 触发 | 动作 | 边界 |
|---|---|---|---|
| H1 写下原则 | 同类选择第二次出现 | 写 trigger/action/prediction/exception | 只写口号不算 |
| H2 先学习后决定 | 证据和选择混战 | 先固定证据截止与未知，再切换决策模式 | 有法定时限时不可无限研究 |
| H3 目标先取舍 | 同时追求互斥结果 | 写优先目标、不可牺牲约束和放弃项 | 目标不能取消他人权利 |
| H4 具体化问题 | 出现“他们不行/文化有问题” | 改成行为、时间、基线和差距 | 人格标签不是问题定义 |
| H5 根因竞争 | 一看到问题就有人归责 | 至少列机制 A/B 与各自区分证据 | 复杂问题未必有单一根因 |
| H6 找可信反对者 | 高置信、不可逆或意见一致得过快 | 找同域记录强且真反对的人 | 任务特定，不建总分 |
| H7 看二三阶 | 短期方案很诱人 | 写受益者、延迟成本、可逆性和外部性 | 不伪造概率 |
| H8 决策模式先于投票 | 团队不知道谁说了算 | 标 advice/consent/vote/owner/algorithm-assisted | 模式须符合授权与规则 |
| H9 原则与结果分开复盘 | 结果揭晓后出现“早就知道” | 保留事前预测与版本，再写运气/机制 | 不覆盖旧记录 |
| H10 3–5 个相关输入优于 20 个噪声 | 参与人数被当作质量 | 选相关、独立、可反驳输入，同时留弱势视角 | 不是精英封闭许可 |

## 六、主工作流：BRIDGE 六步法

这是 **本 Skill 创建的现代综合**（P029），不是原书章节名。

### B — Bound｜先界定目标、风险、权利和决策权

1. 写决策问题，不先写答案；
2. 写优先目标、成功指标、不可牺牲约束；
3. 标领域与真实风险；敏感领域自动 high；
4. 列谁受益、谁承担成本、谁有法定/合同/专业权利；
5. 明确谁 advice、谁 consent、谁 decide、谁 implement、谁可 halt；
6. 紧急义务优先，不以“继续探究真相”拖延保护。

**失败门**：人员、劳动、医疗、教育、信用、执法、内容治理没有以下任一项时，停止行动设计：

- `--accountable-owner`
- `--applicable-rule`
- `--affected-group`
- `--impact-evidence`（真实流程/真实影响，不是模拟自评；提交后仍需核验）
- `--appeal-path`
- `--rollback-trigger`
- `--stop-condition`

### R — Record｜记录现实，而不是宣布现实

建立四栏：

| 观察/用户陈述 | 解释 | 未知 | 来源质量 |
|---|---|---|---|
| 带日期、口径、版本 | 可竞争的意义 | 会改变决定的缺口 | 直接/外部/推断；支持/不支持 |

- 单一指标必须写选择偏差、缺失群体和被优化后是否会失真；
- 当事者体验是影响证据的一部分，不因“主观”被删除；
- 发现版本冲突不调和：并列并指定判别方式。

**失败门**：若关键现实没有 locator/date/version，降级为待核；若解释伪装成观测，拆开后再继续。

### I — Identify｜五步交叉检查 + 原则编译

把当前问题放进原书五步：

1. **Goal**：真正要什么？与欲望、手段、社会地位有什么区别？
2. **Problem**：现实与目标的可观察差距是什么？
3. **Diagnosis**：机制 A/B 是什么？什么数据能区分？不要用“某人不适合”结束诊断。
4. **Design**：方案如何打到机制？依赖、资源和副作用是什么？
5. **Do**：谁何时做什么？何时停止、回滚、复盘？

然后编译原则：

```text
P-v0.1
Trigger：当 [可辨认情境] 且 [边界] 时
Action：优先 [行为/决策规则]
Prediction：在 [窗口] 内，[指标] 将 [方向/范围]
Exception：若 [条件]，不触发或转人工/专业流程
Falsifier：若观察到 [结果]，削弱/退役此原则
Owner / Review date：
```

**失败门**：没有预测、例外或推翻条件的原则不能进入工具；没有竞争诊断的人员“根因”不能进入决策。

### D — Disagree｜设计深思异议，而不是公开辩论秀

1. 每位参与者先独立写观点/置信度，减少级联；
2. 写最强替代方案，不能只写反方弱点；
3. 找相关记录强且真正不同意的人；
4. 展示等权输入，再决定是否存在足够证据做任务特定加权；
5. 检查错误是否相关、历史任务是否可比、样本是否足够；
6. 写谁可能因报复、身份、语言、排班、残障、保密义务或监控而沉默；
7. 记录什么证据让各方改变，以及决定后仍保留的异议。

可靠性记录最小字段：

| 人/来源 | 具体任务 | 预测/判断日期 | 可核结果 | 样本与不确定性 | 利益冲突 | 修正/申诉 |
|---|---|---|---|---|---|---|

**禁止**：`X 的总可信度 82/100`、由同一批既得利益者互相打分、把表达强度当准确率、用 personality type 做权重。

### G — Govern｜把“最佳答案”放回权利与责任系统

先选决策模式：

- **advice**：owner 广泛听取后负责决定；
- **consent**：受影响/有权主体对重大异议有阻断或协商权；
- **vote**：规则明确、选民边界合法，适合价值聚合而非事实真伪；
- **owner**：一个 Responsible Party 决定并公开理由；
- **algorithm-assisted**：工具仅提供结构化建议，可被合格人员理解、覆盖和停止。

治理记录必须包含：

- 最终 owner 与授权来源；
- 采用/拒绝的证据、替代方案和残余不确定性；
- 透明范围与隐私区；
- 影响群体通知、合理便利、代表参与；
- appeal 不由原决定者垄断；
- rollback、stop、事故响应、记录保存与退役。

**失败门**：匿名“系统决定”、owner 无权限/资源、申诉回到同一模型/同一人、或无法停止时，不输出实施建议。

### E — Evaluate｜用事前预测更新原则，不用结果重写历史

- 决策前冻结：原则版本、证据、置信度、预测、基线和 harm 指标；
- 分开：**过程质量**（当时是否合理）与 **结果质量**（后来发生什么）；
- 分群检查收益/伤害，不能只看平均值；
- 记录外部冲击、执行偏差和机制证据；
- 对原则做四选一：`retain / narrow / revise / retire`；
- 保留旧版与 owner，不静默覆盖失败预测。

## 七、透明度比例测试

在公开/录制前依次问：

1. **目的**：公开哪一项决策缺陷？
2. **必要性**：较少侵入的方式能否达到？
3. **对象**：公开逻辑、数据、行为，还是不必要地公开人的身份/脆弱信息？
4. **受众**：谁确有工作需要？全员可见是否只是表演？
5. **时间**：实时公开会不会阻止试验、举报或诚实初稿？
6. **权力**：领导者和弱势成员承受的后果是否对称？
7. **权利**：同意能否撤回？有无访问、更正、删除、代表参与与申诉？
8. **安全**：是否涉及个人、健康、保障、骚扰调查、法律特权、商业秘密或安全？
9. **验证**：透明度是否真的改善问题发现/决策，而非只增加内容量？
10. **退出**：何时停止采集、限制访问、删除或退役？

任何涉及敏感人事材料时，默认**私密、按需访问、独立处理**；“对所有人透明”不是默认值。

## 八、快速决策规则

- 同类决策出现第二次，开始写原则；第一次可以先记案例，不急着普适化。
- 原则没有 trigger/exception/falsifier/version，不进入协议或代码。
- 五步中任何一步缺证据，不跳步补成“人的缺陷”。
- 先显示原始输入，再显示任何权重；没有同域可结算记录就不算权重。
- 记录谁能改权重、谁被权重、谁有权申诉。
- 决策权和知识权分开：最懂的人不一定拥有合法决定权，拥有决定权的人也不因此最懂。
- 公开决策逻辑优先于公开人的脆弱信息。
- 高风险先看真实影响和分群伤害，不拿模拟准确率冒充现场安全。
- owner、appeal、stop、rollback 缺一项，高风险只做缺口清单。
- 复盘先打开原预测，不允许成功后补写“原则一直如此”。

## 九、常见失败模式

| 失败 | 表现 | 修复 |
|---|---|---|
| 原则收藏癖 | 抄几百条，遇事仍凭直觉 | 只保留能触发、预测和更新的 3–7 条活规则 |
| 成功者偏差 | “他富有，所以管理原则正确” | 写竞争解释和不可识别因果 P028 |
| 现实垄断 | 领导的解释被命名为事实 | 观察/解释/未知分栏，允许反证 |
| 五步伪诊断 | 根因总是“人不行” | 竞争机制、岗位设计、资源、激励和系统证据 |
| 透明暴力 | 公开羞辱被称为诚实 | 比例测试、私密反馈、反报复、尊严与申诉 |
| 监控悖论 | 录得更多却得到表演性行为 | 反馈/评价分离，设置团队隐私与试验区 |
| 发言责任倒置 | 弱势者不发言被归责 | 领导承担创造安全、回应和保护责任 |
| 可信度阶级 | 历史高分垄断未来机会 | 任务特定、衰减、冷启动、多元输入和纠错 |
| 循环评分 | 高地位者定义成功，再因成功获得高权重 | 外部/独立结果、预注册口径、利益冲突披露 |
| 类型宿命 | MBTI/画像直接判岗位适配 | 自愿发展使用；选拔必须岗位验证且不得单独决定 |
| 算法洗责 | “系统算出来的” | owner、逻辑、版本、override、appeal、stop |
| 指标即目标 | dots/发言数变成求生游戏 | 检查 gaming、沉默、质量和差异伤害 |
| 结果论复盘 | 赚了就是对，亏了就是错 | 过程/结果分账，保留事前信息与运气 |
| 争议抹平 | 指控与否认被写成“真相在中间” | 保留来源身份、可核争点和未解决状态 |
| 复制桥水 | 不看规模/行业/文化/法域照搬 | 小范围可逆探针；高风险不做文化实验 |

## 十二、表达 DNA

本 Skill 提炼认知结构，不模仿在世作者口吻：

- **句式**：先“目标/现实/差距”，再“机制/原则/预测”，最后“权利/更新”；
- **词汇**：使用“待核、任务特定、竞争解释、事前、版本、owner、appeal、rollback”；
- **作者辨识度**：保留目标—现实、五步、深思异议、可信反对者、机器/算法和原则演化的结构；
- **去模仿**：不冒称“Ray 会说”，不堆砌公式感口号，不以冷硬语气扮演理性；
- **确定性**：A 写“作者主张”，B 写日期/主体，C 写研究/报道边界，D 写“本 Skill 创建”；
- **节奏**：一轮聚焦一个决策、一个主原则、一个最强替代和一个更新窗口；
- **伦理语法**：任何优化建议都带受影响群体、权利、owner、停止与申诉。

## 十三、内在张力（不调和，转成检查）

1. **真相 ↔ 谦逊**：越追求真相，越要防止某人把观点垄断为现实。
2. **透明 ↔ 隐私/安全**：公开逻辑可提高问责，持续暴露会诱发表演、沉默和伤害。
3. **可信度差异 ↔ 平等尊严/机会**：知识权重可以不同，人的权利与价值不能按预测记录排序。
4. **系统一致 ↔ 情境判断**：协议减少任性，也会在新情境中稳定地犯错。
5. **机器视角 ↔ 人的主体性**：流程可重构，人不是输入零件；照护、意义和集体权利不是残差。
6. **开放争论 ↔ 决策闭合**：持续探询有价值，但有时限、责任和紧急义务要求结束争论。
7. **允许错误 ↔ 独立问责**：学习需不掩盖错误；欺骗、违法、伤害和失职仍有责任程序。
8. **有意义关系 ↔ 持续排序/淘汰**：高频评价可能与信任和关系承诺冲突。
9. **结果导向 ↔ 过程正义**：得到好结果不能清除不公平过程，公平过程也不保证幸运结果。
10. **个人责任 ↔ 结构约束**：own outcomes 可增能，也可能把排班、贫困、歧视、残障和权力问题个人化。

## 十四、诚实边界

- 本 Skill 不是 Ray Dalio、Bridgewater、原书替代品或投资建议；
- 无法从公开材料验证 Bridgewater 的权重算法、dots、baseball cards 或其净效果；
- 原书主要是成功者回忆与规范性管理框架，不能仅凭书中案例识别因果；
- 预测领域的加权研究不验证人员总分、人格排序或任意组织决策；
- 心理安全、voice 和 transparency 研究提供条件与反例，不给出跨文化万能配方；
- 新闻调查与机构回应保留争议身份，本包不代替法院、监管、审计或独立调查；
- BRIDGE 未经过外部效度、可靠性或干预效果验证；
- 高风险结果始终是 `governance_review_required`，不是法律、伦理、人事、临床、信用或部署批准；
- 本包没有用户中译本，不能保证中文术语与页码对应特定版次。
