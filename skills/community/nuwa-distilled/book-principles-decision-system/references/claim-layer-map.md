## 明确否定的归因

| 被禁止的说法 | 原因 |
|---|---|
| “BRIDGE 是 Dalio 在《原则》中提出的六步法” | BRIDGE 是 D 层操作化，见 P029 |
| “2011 PDF、2017 书和 2024 Bridgewater 文化声明是同一版本” | 版本坍缩，见 P018–P019 |
| “Bridgewater 成功证明 radical transparency / dots 导致高绩效” | 从共现跳到因果，见 P027–P028 |
| “任务预测中专家加权有效，所以可以给员工一个总可信度分” | 领域与构念越界，见 P023–P025、P032 |
| “算法执行原则，所以决定客观公平且无需负责人” | 编码不移除价值与责任，见 P014–P015、P033、P036 |
| “心理安全就是不批评，或 radical transparency 自动等于心理安全” | 两种概念都被扭曲，见 P010、P020–P022 |
| “后续的 deliberate inclusion 是 Dalio 2017 年已完整提出的制度” | 把 B 层机构演化冒充 A 层原书，见 P019 |
| “调查报道已经证明全部指控 / 机构否认已经推翻全部指控” | 争议证据被错误裁定，见 P027 |

## 禁止坍缩

- 原书主张 **≠** 独立研究结论；
- 作者经验 **≠** 可识别的因果效应；
- 了解现实的目标 **≠** 某位领导拥有现实；
- 透明 **≠** 无边界公开、录制或监控；
- 发言渠道 **≠** 无报复、有效发言或平等影响；
- 任务可靠性 **≠** 人的全局价值；
- 性格偏好 **≠** 能力、岗位适配或命运；
- 原则编码 **≠** 公平、正确或合规；
- owner **≠** 可以不解释的独断；
- 填完高风险字段 **≠** 批准部署。
