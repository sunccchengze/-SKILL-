## 使用顺序

1. 先确定用户要的是 2017 原书还是 Dalio/Bridgewater 后续表达；
2. 在 `claim-layer-map.md` 找声明 ID 和层；
3. 到 `source-notes.md` 检查来源支持与不支持；
4. 只打开当前问题命中的 1–2 个研究轨道；
5. 用 `templates.md` 或 `../scripts/apply_principles.py` 生成初稿；
6. 高风险先完成治理门，不以模板完成冒充批准；
7. 复盘时保留旧原则版本。

## 最小披露

面向用户的短回答不必倾倒全部研究，但必须披露：

- 原书/后续/外部/Skill 的层级；
- 核心证据限制和竞争解释；
- 透明、权重、人员测量或算法化的权利边界；
- 输出的认识论状态；
- 高风险的 owner、真实影响、appeal、stop 和 rollback 缺口。

## 来源 ID 规则

- `PD-01`–`PD-08`：原书书目/授权原文/结构；
- `PD-09`–`PD-10`：其他版本和机构演化；
- `PD-11`–`PD-23`：独立研究、治理、报道和回应；
- `D1`：本 Skill 创建的工作流与制品。

不要仅因 URL 存在就宣称证据有效；每次使用同时读取“不支持”和“版本/局限”。
