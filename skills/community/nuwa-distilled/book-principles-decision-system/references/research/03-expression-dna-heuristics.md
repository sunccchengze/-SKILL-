# Research 03｜表达 DNA、启发式与反模仿

## 任务

提炼《原则》的表达结构，使输出有作者体系辨识度但不模仿在世作者人格，不用“Ray 会说”制造权威。

## 语料边界

- 主要语料：PD-02–PD-07 作者授权原则页面；
- 结构核验：PD-01、PD-08；
- 版本提醒：网页是动态呈现，不作 2017 随机语料或页码来源；
- 本轮没有对全书随机抽 20 段做量化，故不虚报句长、问句率或词频。

## 可观察表达结构

### 1. 层级树

常见形式是：

- 一个总原则；
- 多个子原则；
- 字母/编号下的进一步规则；
- 例子解释何时触发。

优点：可以定位和讨论规则。
风险：编号数量制造完备错觉，用户记住分类而非判断。

### 2. 命令式动作

高频是动词起句：Recognize、Remember、Understand、Make sure、Don’t。

优点：规则可执行。
风险：断言语气会掩盖证据等级，把个人经验写成普遍义务。

### 3. 二元区分

- learning / deciding；
- goal / desire；
- proximate / root cause；
- open-minded / closed-minded；
- equal-weighted / believability-weighted。

优点：降低认知混乱。
风险：连续、情境性和第三选项被切掉。

### 4. 方程/机器隐喻

如 pain + reflection = progress、组织机器、原则算法。

优点：强调因果、反馈和可操作性。
风险：公式感不等于经过测量；人类关系和制度不是封闭机械系统。

### 5. 结果导向与高层视角

表达经常把事件放回目标、跨时间模式和机器设计。

优点：减少局部症状修补。
风险：结果可遮蔽过程正义，higher level 可成为对局部伤害的抽象化。

### 6. 强确定性

作者常用最重要、最佳、几乎总是等强表达。

优点：留下清晰立场，便于反驳。
风险：这是作者确信程度，不是外部证据强度。

## 不进行伪量化

正版 Nvwa 建议随机抽样并量化表达 DNA；当前包未持有可合法分析的完整电子文本，也未建立随机样本。

因此：

- 不报告平均句长；
- 不报告第一人称比例；
- 不报告“radical”每千字次数；
- 不把授权网页的选择性片段当全书总体；
- 将缺口写入诚实边界，而不是编一个量表结果。

## 中性输出 DNA

本 Skill 采用“结构同源、口吻去模仿”的表达：

1. 先写目标、现实、差距；
2. 再写机制、原则、预测；
3. 然后写最强异议、决策权和权利；
4. 最后写结果、版本和退役条件。

词汇保留：

- 原则、现实、目标、问题、诊断、设计、执行；
- 深思异议、任务特定可靠性、Responsible Party；
- 事前预测、版本、更新。

词汇校正：

- radical transparency → 比例透明/隐私区；
- believability → 任务特定可靠性，不写人的总分；
- machine → 流程/系统镜片，不称人是零件；
- tough love → 不作为羞辱、攻击或强制公开许可；
- pain → 不浪漫化创伤、骚扰或违法伤害。

## 十条启发式的形成

### H1 第二次出现时写原则

来自 P002/P011 的经验压缩，但阈值“第二次”是 D 层实用触发，不是作者原数值。

### H2 先学习后决定

来自 P006；D 层增加信息截止，防止无限研究。

### H3 目标先取舍

来自五步的 Goal；D 层增加不可牺牲权利。

### H4 把问题写成可观察差距

来自 P005/P009；禁止人格标签是安全校正。

### H5 至少两个竞争诊断

原书强调 root cause；“至少两个”是 D 层抗确认偏误门。

### H6 找有记录的反对者

来自 P008/P013；PD-14 仅在预测任务提供外部条件性支持。

### H7 写二三阶后果

来自 P007；D 层要求受益/成本分群和可逆性。

### H8 先选决策模式

来自 P014/P017 的 RP/治理张力；advice/consent 分类是 D 层。

### H9 结果前冻结原则版本

来自 P002/P011/P015 的学习逻辑；版本日志是 D 层。

### H10 少量相关输入优于大量噪声

受作者“3–5 > 20”启发；D 层明确不能变成精英闭门或压低弱势声音。

## 反模式表达

禁止以下句式：

- “Ray Dalio 一定会告诉你……”
- “成功已经证明这个原则……”
- “最可信的人说了，所以事实是……”
- “情绪是低级大脑，应被排除……”
- “为了真相，你应该接受公开羞辱……”
- “这位员工就是不适合/不可信……”
- “算法比人客观，所以让它决定……”
- “Bridgewater 后来强调 inclusion，说明原书早已预测现代治理……”

替代句式：

- “Dalio 在 2017 书中主张……；独立证据只支持到……”
- “本次把它当原则假设；事前预测和推翻条件是……”
- “该来源在这类任务有 __ 条可核记录；不能外推到人格/其他领域。”
- “透明目的为 __；较低侵入替代为 __；隐私区为 __。”
- “最终决定由 __ 依据 __ 授权承担，仍可通过 __ 申诉。”

## 本轮导致的工作流决定

1. 输出保持树状和动作化，但每项动作旁加边界。
2. 不模仿强确定性；将确定性翻译为证据层和置信度。
3. 原则必须从口号改为可反驳卡，而不是复制命令句。
4. 机器/公式语言后必须紧跟不可量化与权利限制。
5. CLI 输出使用中性 `TODO`，不自动替用户做最终判断。
6. “表达 DNA”明确披露未完成全书随机量化，避免伪研究深度。

## 失败门

- 读起来像通用 AI，删书名后没有目标—现实/五步/异议/规则化结构；
- 读起来像 Dalio 角色扮演，替作者发言；
- 用强命令语气冒充证据；
- 大量抄名言而无触发与限制；
- 以冷酷、羞辱作为“真实”；
- 报告未实际计算的表达统计。

## 未解决问题

- 需要合法的完整版本才能做随机 20 段量化；
- 中文译本的句法会混入译者风格，需与英文分开；
- Principles.com 的层级呈现可能由网站产品设计塑造；
- 作者演讲/长访谈中的即兴表达尚未做独立语料分析；
- “强确定性”在不同章节是否有系统差异仍未知。
