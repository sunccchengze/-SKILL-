# 可选跨书桥：变化扫描 → 行为实验

> **层级：D，现代跨书操作化。** 本桥由本仓库创建，不是《周易》古经、《十翼》、历史注家或 James Clear 的原有章节，也不是经整体实验验证的干预方案。它不声称 Clear 受《易经》影响，也不把古典概念说成现代习惯科学。

## 独立调用优先

两个 Skill 永远可以单独使用：

- **变化、角色、关系、时机和不确定决策**：只调用 `book-yijing-change-decision`；
- **重复行为、线索、摩擦、最低入口和恢复**：只调用 `book-atomic-habits-system`；
- **情境变化正在破坏/要求重建一项日常行为**：才考虑本桥。

不要因为两包相邻就自动混用。用户只问一书时，默认保持单包回答。

## 何时组合

适合：

- 换导师、换项目、搬家、旅行或换班后原习惯失效；
- 组织关系/权限变化，需要先判断可控范围，再设计重复行动；
- 新方向仍不确定，希望用短周期行为实验补证据；
- 原行为连续失败，怀疑问题来自情境结构而不只是摩擦。

不适合：

- 用古典类比证明某习惯必然成功；
- 用打卡结果反推卦象“灵验”；
- 医疗、法律、财务、安全或临床问题中把两套框架叠加成伪专业意见；
- 为复杂战略问题强行找一个微习惯，掩盖资源和权力约束。

## 桥接流程

### 1. CHANGE 先扫描变化

调用 `book-yijing-change-decision`，但不自动起卦：

- **事实**：环境、时间、角色、资源实际改变了什么；
- **假设**：对时机、协同或趋势的解释；
- **未知**：还需核验什么；
- **时—位—应—势**：窗口、权限、关键关系和增强/减弱的力量；
- **红线**：不可用小实验替代的专业判断；
- **可逆行动**：需要用行为收集什么证据。

### 2. 写清楚交接字段

```markdown
- 已确认的情境事实：
- 仍是推测的解释：
- 行动者可控范围：
- 关键锚点何时/为何改变：
- 要通过重复行为检验的假设：
- 风险与停止条件：
- 观察周期：7–14 天（不是习惯形成期限）
```

不得把古典类比放入“已确认的情境事实”。

### 3. ATOM 把可逆行动装成短实验

调用 `book-atomic-habits-system`：

- 只选一个可观察行为；
- 选择新情境中真实稳定的线索；
- 同时定义约两分钟入口、标准版、可选进阶版与封顶；
- 用四定律只改 1–2 个杠杆；
- 记录重复、情境一致性、启动难度、真实产物和副作用；
- 漏做后在下一个安全线索恢复，不作身份审判。

### 4. 结果回流到 CHANGE

周期结束后，将观察写回：

- 哪个事实/假设得到支持或削弱；
- 失败来自线索、能力、资源、关系还是目标价值；
- 时、位、应、势哪项改变；
- 继续、缩小、换锚点、换路径或停止；
- 哪个古典类比或身份描述已经失效。

习惯重复只是证据之一，不证明战略方向正确。

## 一个最小案例

**问题**：博士生换实验室后，原来的午饭后阅读习惯消失。

### CHANGE 输出

- 事实：新实验室午饭时间不固定，工位与餐区相距远；
- 假设：阅读消失主要是旧锚点丢失，而不是“变懒”；
- 未知：每日实验结束后的记录动作是否更稳定；
- 可逆行动：测试“保存当天实验记录后打开当前论文”的新锚点 7 天。

### ATOM 输出

- 线索：保存当天实验记录后；
- 最低入口：打开论文并读两分钟；
- 标准版：读摘要并写一个与实验相关的问题；
- 封顶：不因补读侵占睡眠或实验安全检查；
- 记录：线索机会、是否开始、版本、启动难度、问题质量；
- 复盘：若实验记录本身也不稳定，返回 CHANGE 检查流程/权限，而非继续加提醒。

## 显式调用示例

```text
请组合使用 book-yijing-change-decision 与 book-atomic-habits-system，并明确标注“现代跨书桥”。
先用 CHANGE 分开事实、假设、未知和时—位—应—势；再只把可控的一个行动交给 ATOM，
设计 7 天观察实验。不要起卦，不承诺形成期限，并在末尾把行为结果回流到原假设。
```

## 最终边界

- 经典文本提供反思词汇，不提供外部事实；
- 习惯研究提供概率性机制，不保证个人结果；
- 本桥提供流程，不证明两套理论历史相连或科学等价；
- 两个 Skill 的来源层级、安全规则和独立调用条件持续有效。
