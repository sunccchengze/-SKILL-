# Research pass 06｜TITAN-TRACE 综合、对抗样例与停止条件

## 综合目标

保留原书最可迁移的操作张力：广泛采样、用问题挑战默认、从他人经验生成候选、亲自记录与试验；同时加入原选编不能提供的来源账本、成功样本偏差、COM-B、N-of-1 和风险门。

## 为什么是十步

`Target → Inventory → Triage → Adapt → Name → Take baseline → Run → Archive → Challenge/Choose → Export`

设计约束：

- 在动作前强制来源、偏差和安全分诊；
- 在 routine 前强制机制与 COM-B；
- 在结果前强制基线、比较和阈值；
- 在结论前强制伤害、竞争解释和唯一决策；
- 在传播前强制有限外推。

## 对抗样例

### 样例 A｜“五位顶尖人士都做，所以我也做”

- 失败点：选择成功、编辑频次、分母缺失、权威效应。
- 路由：先找独立证据；如果是低风险流程，再做单变量试验；高风险则停。

### 样例 B｜“我照做三天，第一天很好”

- 失败点：无基线、自然波动、期待效应、事后挑最佳日。
- 路由：不能追认成有效；若仍值得且安全，重建协议。

### 样例 C｜“两个名人建议相反，谁更厉害听谁”

- 失败点：把成就当跨域证据。
- 路由：按目标、机制、基线、情境、风险与独立证据分支；允许都搁置。

### 样例 D｜“补剂只要低剂量就做 N-of-1”

- 失败点：相互作用、产品差异、个体禁忌、工具无法验证专业复核。
- 路由：CLI fail closed；由合格专业人员负责。

### 样例 E｜“我要整本人物精华，越详细越好”

- 失败点：版权替代 + 崇拜式组织。
- 路由：拒绝替代部分，转到一个目标/合法短片段的机制与证据分析。

### 样例 F｜“追踪 20 个指标，总能发现点东西”

- 失败点：多重比较、测量反应、记录负担和探索性 HARKing。
- 路由：一个主结果；探索指标不得事后替换。

### 样例 G｜“结果没变，但我买了设备，继续堆叠”

- 失败点：沉没成本与优化剧场。
- 路由：按 stop；设备不进入收益判据。

### 样例 H｜“机会结构有问题，建议我更早起”

- 失败点：把结构缺口变成个人动机/睡眠代价。
- 路由：COM-B 指向 opportunity，优先改权限、排程、环境或协作。

## 停止条件总表

任一即停：

- 进入 professional-review/no-self-experiment 域；
- 新症状、功能下降、异常情绪或伤害阈值；
- 必须欺骗/侵犯他人/违法才执行；
- 两个及以上主要变化无法分离；
- 关键数据系统性缺失且无法修复；
- 每日记录超预算或挤占目标本身；
- 达到预定最大天数；
- 结果阈值未达或代价超过预设线；
- 用户要求把个人观察传播为普遍处方。

## 输出质量门

完整结果应能回答：

1. 这是谁在什么原始位置报告的？
2. 它是哪种 claim，而非笼统“观点”？
3. 独立证据支持什么精确对象？
4. 成功样本与叙事选择遗漏了谁？
5. 迁移时删掉了什么身份/资源/仪式？
6. COM-B 主瓶颈有何观察依据？
7. 为什么风险门允许/拒绝？
8. 基线、比较、主结果、伤害和阈值是什么？
9. 哪两个以上竞争解释仍成立？
10. 决定是什么，以及绝对不能从数据推出什么？

## Nuwa deep-tier 自检

- 七个模型均含失效边界；
- A/B/C/D 来源显式；
- 表达 DNA 不是模仿作者口吻，而是校准、来源先行的独立风格；
- 张力不被“大胆试验”口号消解；
- 工具、文档、测试和风险域使用同一枚举；
- 默认中文并保留方法英文；
- 不保存原书大段文本。

## 最终决策

采用 `book-tools-of-titans-experiment-lab` 作为独立 Skill 名称，以个人实验“实验室”而非“名人智慧库”定位。类别放 `general`，因为它跨工作、学习与低风险生活流程；医疗、危险体能与高风险金融被排除，不因主题词进入相应处方类别。
