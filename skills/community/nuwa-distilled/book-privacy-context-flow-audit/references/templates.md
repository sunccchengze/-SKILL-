## P6 Nine-step decision heuristic
1. 描述新实践和 information flows：
2. prevailing context、嵌套 context：
3. actors/capacities：
4. attributes 与 transmission principles：
5. entrenched norms 与 significant departures：
6. prima-facie status（conforming/departure/contested/unknown）：
7. moral/political factors（power/autonomy/justice/rights/harm/benefit）：
8. contextual values/ends/roles 被促进或破坏：
9. allow/modify/pause/reject + reasons/conditions：

## P12 High-impact release gate
- accountable owner / authority；applicable rules / DPIA；
- affected group + verified impact evidence + differential harms；
- notice/contest/correction/deletion/independent appeal；
- security and incident response（separate from CI）；
- stop/rollback/vendor deletion/model-memory handling；
- status：`prima_facie_privacy_audit_not_legal_approval`。
