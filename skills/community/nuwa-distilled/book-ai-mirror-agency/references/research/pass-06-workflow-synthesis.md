# Pass 06｜工作流综合与验证问题

AGENCY-MIRROR：Harm/rights gate → Author purpose → Inspect mirror → Separate is/ought → Map delegation → Generate counterfutures → Rehearse judgment → Restore contestability → Choose least erosion → Record/revisit。

关键验收：

- 查询 AI 前是否由人和受影响者写目的/底线？
- 每个关键声明是否分为观察、预测、因果、价值、约束或决定？
- 是否明确目的、权利权衡、最终授权和申诉裁决不可把责任交给模型？
- 是否存在受影响者路径和无 AI/低技术路径？
- 退出/复审在成本、语言、能力与反报复上是否真实？
- 是否追踪技能、校准、覆写质量、异议和选项多样性并设置撤回条件？

只要高影响系统缺真实申诉、暂停或具名责任，审计结论应为“不部署/先治理”。
