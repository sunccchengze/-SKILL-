# References 导航

本目录按“来源—层级—研究—执行”组织：

- [`source-notes.md`](source-notes.md)：来源 URL、证据等级、用途与局限；
- [`claim-layer-map.md`](claim-layer-map.md)：声明属于古经、《十翼》、解释史还是现代操作化；
- [`templates.md`](templates.md)：可复制的分析、信号、情景与更新模板；
- [`../../book-change-habit-bridge.md`](../../book-change-habit-bridge.md)：可选 D 层现代跨书桥，默认不启用；
- `research/01-textual-strata.md`：复合文本与层累；
- `research/02-primary-passages.md`：少量公版短句卡；
- `research/03-mental-models.md`：六模型；
- `research/04-interpretive-traditions.md`：王弼、朱熹、象数/义理与争议；
- `research/05-modern-decision-workflows.md`：CHANGE 工作流和案例；
- `research/06-history-critique-bibliography.md`：历史、批评与继续阅读。

## 使用顺序

1. 先在 `claim-layer-map.md` 判断层级；
2. 到 `source-notes.md` 检查声明边界；
3. 只打开与当前问题相关的研究笔记；
4. 用 `templates.md` 落到可复盘输出。

不要把研究笔记整段倾倒给用户。回答只带当前判断所需的最小原文、解释差异和来源。
