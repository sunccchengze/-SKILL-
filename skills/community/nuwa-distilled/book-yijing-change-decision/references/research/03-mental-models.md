# 03｜六个心智模型的推导与组合

## 目的

把经典资源转成可以执行、可以失败、可以更新的模型，而不是只留下格言。每个模型都包含：来源层、解释桥、现代操作化、决策规则、证伪/失效方式。

## 1. 生生模型：状态 = 生成过程的暂时截面

### 推导

《系辞上传》以“生生”解释“易”。本 Skill 不把它直接等同现代过程哲学或复杂系统理论，而只保留一个谨慎的观察转换：从名词状态转向生成机制。

### 工具

```text
当前状态 S
← 哪些重复活动 R 维持？
← 哪些资源 I 输入？
← 哪些反馈 F 强化/削弱？
← 哪些外部条件 C 允许？
```

### 规则

- 若停止一个关键输入会迅速崩解，S 不是“天然稳定”，而是昂贵维护；
- 若只改结果指标不改生成循环，预期反弹；
- 每个过程模型至少写一个可观测指标。

### 反例

短期随机波动不一定是新过程；先看重复性和机制。

## 2. 时—位—应模型：适配优先于抽象正确

### 推导

卦爻由位置、承乘应比和具体卦时获得意义，历代术语用法有差异。本 Skill 采用“时机—角色—关系”的最低公共结构，并添加现代“势”作为分析栏。

### 工具

| 项 | 问题 | 可观测证据 |
|---|---|---|
| 时 | 哪个阶段？窗口多长？ | 截止日、采用率、准备度 |
| 位 | 我实际能决定什么？ | 授权、职责、能力、义务 |
| 应 | 谁能协同/阻碍？ | 承诺、激励、依赖、沟通 |
| 势 | 什么趋势正在增强？ | 连续数据、资源流、规则变化 |

### 规则

- “有能力但无授权”先处理位；
- “有授权但无协同”先处理应；
- “方向合理但窗口未到”缩小试验，不必全停；
- 只有事后解释、没有事前预测差异的“得时得位”判断应降级。

## 3. 刚柔调节模型：模式可以切换

### 推导

刚柔相推提供关系性语言。本 Skill 把它转为两组行动能力，不转为人格标签。

| 刚性模式 | 柔性模式 |
|---|---|
| 定边界、做取舍 | 收信息、容纳差异 |
| 快速推进、公开承诺 | 等待窗口、低调试验 |
| 标准化、减少歧义 | 本地适配、保留余地 |
| 直接反馈 | 探询式反馈 |

### 选择规则

- 风险不可逆且证据不足：偏柔，先探查；
- 权责模糊导致重复损失：偏刚，明确边界；
- 利益相关者防御上升：先柔性理解，再刚性决策；
- 价值红线被突破：刚性停止，不用“柔”合理化纵容。

### 组合

刚柔不是折中平均。可以“目标刚、路径柔”“伦理边界刚、时间安排柔”。

## 4. 知几模型：弱信号不是神秘预兆

### 推导

“几”启发对初萌变化的注意。现代化必须加上噪声控制，否则会鼓励确认偏误。

### 三层阈值

1. **观察**：一次异常；只记录，不下结论；
2. **核验**：连续出现或跨来源出现；主动寻找替代解释；
3. **行动**：达到事前阈值；执行低成本响应。

### 信号卡

```text
信号：
基线：
出现频率/幅度：
首选解释：
至少一个替代解释：
漏报成本：
误报成本：
核验方式与日期：
行动阈值：
```

### 失败条件

如果没有基线、没有替代解释、没有阈值，这不是“知几”，只是故事化。

## 5. 安不忘危模型：顺境中的最小预演

### 推导

经典警戒可转为风险维护，但应防止把谨慎变成焦虑。

### 10 分钟预演

- 当前成功依赖的三个条件；
- 最可能先坏的一个；
- 最早可见信号；
- 一个不超过预期损失 10% 的缓解动作；
- 一项不值得防范的低概率低损失风险。

### 规则

风险条目必须同时写“证据、影响、缓解成本”。没有这三项，不进入行动列表。

## 6. 穷—变—通—久模型：改变受阻结构

### 推导

“变”在这里不能被简化为盲目变化。现代决策要明确变化对象。

### 诊断树

```text
目标仍值得吗？
├─ 否 → 有序退出/重定目标
└─ 是 → 路径是否可行？
   ├─ 否 → 换路径
   └─ 是 → 资源足够？
      ├─ 否 → 减范围/增资源
      └─ 是 → 节奏/关系/反馈是否阻塞？
         ├─ 是 → 改结构变量
         └─ 否 → 可能只是正常学习期，继续并设复盘点
```

### 规则

- 同故障重复两次且根因未变，至少改变一个结构变量；
- 每次改变只保留少量变量，便于判断因果；
- “通”要用指标定义，例如周期缩短、错误率下降、沟通等待降低；
- “久”包括维护成本和副作用，不只看短期突破。

## 六模型组合顺序

推荐顺序：

1. 生生：找生成过程；
2. 时位应：找适配条件；
3. 知几：找早期信号；
4. 刚柔：选行动模式；
5. 安不忘危：加保护；
6. 穷变通久：在受阻时改变结构。

不要一次把六个模型全部展示给用户。按问题选择 2–3 个，并在结尾说明未使用哪些、为什么。

## 质量判准

一个模型只有满足以下条件才算“可执行”：

- 能改变一个具体观察或选择；
- 能写出至少一个失败条件；
- 能由新事实更新；
- 不依赖神秘权威才能成立；
- 与原典的连接被标为文本、解释或类比中的哪一种。
