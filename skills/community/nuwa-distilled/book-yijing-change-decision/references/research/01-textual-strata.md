# 01｜文本层累：先问“哪一部《易》”

## 研究问题

为什么不能把今天收到本《易经》中的所有句子都视为同一时代、同一作者、同一目的的作品？

## 工作性结论

“《易经》”在日常语言里往往指收到本整体；严谨使用时至少要区分：

1. **卦画系统**：由阴/阳爻线组成八卦、六十四卦；图式和用法也有形成史；
2. **《周易》古经**：卦名、卦辞、爻辞构成的占筮文本核心，通常放在西周语境理解；
3. **《十翼》/《易传》**：后出的多个解释篇，把材料伦理化、宇宙论化和哲学化；
4. **汉代以来易学**：象数、义理、占筮、政治伦理、宇宙论等多条路径；
5. **现代全球重释**：心理学、管理、系统论和个人成长类比；其中许多是现代用途，不是历史原义。

上述每层内部也不整齐。日期、作者、篇章形成和出土文本关系仍有争议，所以本 Skill 只采用足以避免误归因的概略层级，不装成完整经学定论。

## 古经与传文的功能差异

### 古经

卦爻辞往往短、具体、含古代礼制、征伐、婚姻、祭祀、迁徙、灾异等语境。它们不天然组成现代读者期待的完整哲学论证。脱离字义、制度史和卦爻位置，容易把陌生语句改写成泛化鸡汤。

### 《十翼》

《彖》《象》《文言》《系辞》《说卦》《序卦》《杂卦》等传篇承担解释工作。现代研究一般不接受“孔子亲自写成全部《十翼》”作为历史事实。《十翼》将卦爻放进更广的伦理、政治、宇宙和修养框架；这正是后世哲学资源丰富的原因，也正是回答时必须标“传”的原因。

### 后世解释

- 汉代传统常发展象数、卦气、灾异与宇宙对应；
- 王弼着重透过象数把握义理，常被概括为反对烦琐的机械对应；
- 唐代《周易正义》整合经注，形成重要官方经典形态；
- 宋代理学家以修养、义理和占筮重新组织阅读；朱熹并不简单排除占筮；
- 现代考古、古文字和思想史研究又改变了对古经语境的认识。

这些路径不是“越晚越错”，而是回答不同问题。错误在于不标路径，却把选择性解释说成文本唯一声音。

## 名称使用规则

- 指卦辞/爻辞：优先写“《周易》古经”。
- 指《系辞》等：写“《易传》/《十翼》中的《系辞》”。
- 泛指收到本及传统：可以写“《易经》传统”，但随后说明具体层。
- 用户说“孔子说”：先核查是否只是传统归名；现代历史判断要另列。
- 用户说“伏羲发明全部易经”：区分文化传说与可证历史。

## 回答示例

不合格：

> 《易经》说“穷则变，变则通，通则久”，所以文王认为创业一定要转型。

合格：

> “穷则变，变则通，通则久”见《系辞下传》，属于后出的《易传》解释层，不是某卦的西周爻辞。今天可以借它检查“目标、路径、资源、节奏”中哪一项已受阻；“一定要转型”仍需由市场、成本和试验数据判断。

## 深层风险：层级坍缩会造成什么

1. **作者神化**：把长时期集体形成说成一个圣人的全知设计；
2. **概念回投**：将现代“二进制、系统科学、量子”等术语读回古代；
3. **解释免疫**：任何结果都能由不同层的句子事后解释；
4. **文化抹平**：忽略占筮、礼制、政治和修养的历史差异；
5. **决策越权**：用经典权威压过现实证据和当事人选择。

## 可操作检查

每次使用一条经典材料，写一行内部标签：

```text
[层] A古经 / B十翼 / C历史解释 / D现代操作化
[定位] 卦-爻 / 传篇-章段 / 注家-作品 / Skill自建
[把握] 已核原文 / 仅二手摘要 / 尚待核验
[允许] 可支持的反思问题
[禁止] 不能推出的事实
```

若无法填满，宁可只说“我尚未核对具体出处”，不要制造出处。
