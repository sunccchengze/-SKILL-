# 《原子习惯》行为系统 Skill

Nuwa deep-tier 的中性书籍蒸馏包：保留 James Clear《原子习惯》的实用框架，同时用独立习惯研究校正定义、时长、身份、情境和自动性主张。

## 它能做什么

- 把结果目标改成可在稳定线索后重复的行为；
- 诊断线索—渴求—反应—奖励链条；
- 使用四定律/反转、实施意图、习惯叠加、环境与摩擦设计；
- 同时定义两分钟入口、标准行为、进阶版和安全封顶；
- 追踪情境、重复和启动自动性；
- 为漏做、旅行、换班、搬家和旧线索回归设计恢复方案。

## 快速调用

```text
请使用 book-atomic-habits-system，为“午饭后读论文”设计一个14天系统。
请分开作者框架与研究证据；给实施意图、四定律矩阵、两分钟入口、标准版、封顶、恢复协议和复盘指标。不要承诺固定形成天数。
```

减少行为：

```text
请使用 book-atomic-habits-system 分析我睡前刷手机的线索和即时功能。
用四定律反转，但保留夜间紧急联系；设计替代行为，不做自律羞辱。
```

CLI：

```bash
python3 scripts/design_habit.py --behavior "读摘要并写一个问题" \
  --value "理解证据" --identity "会留下阅读证据的研究者" \
  --cue "午饭后坐回工位" --location "书桌" \
  --tiny-start "打开论文并读两分钟" --standard "读完摘要并写一个问题"
```

## 重要边界

- 习惯不等于高频行为；核心是情境线索触发的学习性自动化；
- “每天进步 1%”是说明累积效应的类比，不是 37 倍结果保证；
- 形成时间因人和行为差异很大，不使用 21 天或 66 天硬承诺；
- 身份是可修订方向，不是一次漏做后的人格审判；
- 成瘾、进食障碍、强迫、自伤和医学风险需要专业支持。
