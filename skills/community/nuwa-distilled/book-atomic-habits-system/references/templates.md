# 可复制模板

## 1. ATOM 完整工作表

```markdown

- 观察周期：7 / 14 天（不是形成期限）
- 复盘日期：

- 需要专业支持或合理便利：

## T｜一个可观察行为
- 当前要做/减少的行为：
- 定义为“发生”的标准：

## O｜当前循环

- 反应：

## M｜可修订身份

- 当前行为如何提供一票证据：
- 何种新证据会让我修订：

## I｜安装线索
- 实施意图：当___在___发生，我会___。

- 情境变化时的新锚点：

## O｜四定律
| 维度 | 建立：显眼/有吸引力/容易/满足 | 减少：不显眼/无吸引力/困难/不满足 |
|---|---|---|
| 设计 | | |
| 风险/副作用 | | |

## M｜行为梯度
- 最低入口（约两分钟）：
- 标准行为（有真实价值）：
- 进阶版：
- 安全封顶/停止条件：

## M｜测量与恢复
- 重复：
- 情境一致性：
- 启动难度 1–5：
- 真实产出/质量：
- 漏做后下一安全线索的动作：
- 连续同点失败两次后只改一个变量：

## R｜复盘系统
- 有效信号：
- 副作用：
- 继续 / 缩小 / 扩展 / 换锚点 / 停止：
- 下周期唯一修改：
```

## 4. 四级行为卡

```markdown
- 最低入口：只降低启动摩擦，约两分钟
- 标准版：本周期真正希望重复的有效行为
- 进阶版：精力/时间允许时可选
- 封顶：保护安全、睡眠、恢复或质量的停止条件
- 从最低到标准的自然桥：
- 何时扩展：
- 何时缩回：
```

## 6. 减少行为与替代卡

```markdown
- 要减少的具体反应：
- 最常见线索：
- 即时功能（安抚/社交/刺激/逃避/止痛/其他）：
- 移除或隔离线索：
- 增加的安全摩擦：
- 满足相同功能的最低替代：
- 必须保留的紧急/照护通道：
- 若涉及依赖、戒断、进食障碍、强迫、自伤：停止并转专业支持
```

## 7. 漏做恢复卡

```markdown
- 漏做的线索机会：

- 届时做的最低版：
- 不采用的补偿（熬夜/双倍/极端节食或运动/羞辱）：

```
