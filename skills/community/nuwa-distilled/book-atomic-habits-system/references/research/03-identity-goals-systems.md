# 03｜身份、目标与系统：如何使用而不僵化

## 1. 三者不是替代关系

```text
价值/身份方向 → 选择值得追求的目标
目标 → 定方向、约束和评价标准
系统 → 组织情境中的重复行为与反馈
结果 → 反过来更新目标、系统和自我理解
```

只讲目标：知道终点，却不知道下一次线索后做什么。
只讲系统：流程高效，却可能优化错误目标。
只讲身份：容易产生鼓舞，也容易变成羞耻或自证循环。

## 2. 身份语言的有效形式

建议句式：

> 我在练习成为一个会 [可观察行为] 的人，因为我重视 [价值]。当前证据是 [具体行为]；新证据出现时可以修订做法与身份描述。

例：

- 好：“我在练习成为会保留可复核分析记录的研究者。”
- 差：“真正的研究者每天都读十篇论文。”
- 好：“我会保护睡眠，以支持长期研究。”
- 差：“自律的人从不休息。”

## 3. 两层身份

为降低僵化，区分：

- **价值身份**：诚实、关怀、求知、可靠等较宽方向；
- **策略身份**：“晨跑者”“每天五点写作者”等具体方式。

环境或健康变化时，策略可以换，价值不必被否定。夜班研究者不需要坚持“晨型人”身份，仍可实践稳定运动。

## 4. 习惯—身份证据的边界

Verplanken & Sui (2019) 观察到习惯与“真实自我”、价值等关联；研究也承认关系并非在所有行为中一致。身份可能影响意图和选择，重复行为也可能改变自我知觉，两者还受社会角色和价值影响。

因此：

- 可以用身份提高意义感；
- 不应把相关关系说成单向因果；
- 对新身份不必等待“相信了才行动”；
- 一次行为是微弱证据，不是终审；
- 有害身份（“我就是酒鬼/拖延者/失败者”）应拆成线索与行为，不固化。

## 5. 目标的四种用途

1. **方向**：什么结果值得？
2. **约束**：哪些代价不可接受？
3. **反馈**：系统是否有效？
4. **退出**：何时停止或换方向？

每个习惯系统都应有“停止理由”。如果读论文习惯只增加篇数、不增加理解，目标反馈要求更换指标。

## 6. 系统审计

| 层 | 问题 |
|---|---|
| 输入 | 时间、工具、健康和权限是否足够？ |
| 线索 | 是否明确、稳定且及时？ |
| 行为 | 最低版是否可做？标准版是否有价值？ |
| 反馈 | 是否及时、诚实、不过度游戏化？ |
| 结果 | 是否朝目标前进？有何副作用？ |
| 维护 | 情境变化后能否迁移？成本是否可持续？ |

## 7. 何时不使用身份框架

- 用户正因完美主义、自我厌恶或强迫而受苦；
- 身份标签会触发群体排斥、道德优越或饮食/运动伤害；
- 行为主要受资源、排班、疾病或照护约束；
- 用户只是需要一次性任务流程，而不是长期习惯；
- 目标尚未确定，过早身份承诺会锁定错误方向。

此时可只用价值、环境和下一步行为，不强迫写身份句。

## 8. 决策规则

- 身份句若无法容纳休息、失败和更新，重写；
- 目标结果连续两次不改善，审计系统而非加码身份；
- 系统指标变好、真实结果变差时，真实结果优先；
- 新证据与原身份冲突时，允许身份变得更宽或更准确；
- 不用职业/道德身份迫使用户承受不安全代价。
