# 06｜应用边界、失败模式与领域案例

## 1. 习惯工具不是临床治疗

以下情况不应提供“自己按四定律戒掉”的简化方案：

- 酒精、苯二氮卓类或其他可能产生危险戒断的依赖；
- 阿片、兴奋剂、赌博等成瘾；
- 神经性厌食、暴食/催吐或强迫运动；
- 自伤、躁狂、重度抑郁、强迫症状；
- 行为与家庭暴力、控制或剥削相连。

先安全、医疗和合格专业支持。行为设计仅在专业方案允许时作为辅助。

## 2. 学习与研究

### 好目标

自动化启动与记录，而非“自动化思考”：

- 打开当前论文；
- 写一个阅读问题；
- 建立可核验笔记；
- 实验后立即写元数据。

### 风险

- 追篇数导致浅读；
- 用 AI 摘要替代原文；
- 以连续写作为通宵理由；
- 把科研产出归因于自律，忽略导师、资源和伦理。

## 3. 运动

- 入口和环境可降低启动摩擦；
- 训练内容应符合健康状况和专业建议；
- 设封顶、休息、疼痛/异常症状停止条件；
- 不把体重或外形当每天可控的“习惯”；
- 有进食障碍/强迫运动迹象时停止游戏化。

## 4. 用药

习惯工具只能帮助按既有医嘱执行：稳定线索、药盒、记录。不能建议改变剂量、停药或合并药物。涉及副作用、漏服或剂量问题，联系医生/药师。

## 5. 睡眠

可以设计固定降刺激线索、光线/设备环境和睡前流程，但失眠、睡眠呼吸问题、躁狂或严重日间功能受损需专业评估。夜班/照护者不应被“早起身份”羞辱。

## 6. 数字行为

减少刷手机不能只封锁：先识别社交、工作、无聊、情绪调节和紧急联系功能。设计白名单、安全通道和替代行为。组织强制即时响应时，个人通知设置可能不是根因。

## 7. 团队与组织

可以改变默认会议、模板和审查路径，但必须：

- 不以“好习惯”监控员工私人生活；
- 不用 streak 排名羞辱；
- 让行为和激励一致；
- 保留安全/伦理复核摩擦；
- 先改制度瓶颈，不把系统失败推给个人。

## 8. 常见失败诊断树

```text
没做？
├─ 线索没出现/没看见 → 换稳定锚点或可见性
├─ 线索出现但忘了 → 临时支架 + 减少竞争线索
├─ 想做但太难 → 缩入口、备工具、补技能/资源
├─ 做了但不重复 → 检查即时体验、价值、奖励与副作用
├─ 只做最低版 → 定扩展条件和标准产出
├─ 换环境就消失 → 重装新情境线索
├─ 打卡很好、结果不好 → 改指标或停止系统
└─ 有临床/安全风险 → 停止自助诊断，转专业支持
```

## 9. 不能归因于书的综合

ATOM 九步法、上述诊断树、四级行为、情境迁移和封顶概念是本 Skill 的安全/执行综合。它们受作者框架和研究启发，但不是书中原章节，也未经作为整体方案验证。

## 10. 与其他方法的边界

- BJ Fogg/Tiny Habits：锚点、微行为、庆祝有重叠；不要把其概念改名后归 Clear；
- Charles Duhigg：cue–routine–reward 的大众化表达影响明显；
- Gollwitzer：实施意图是独立研究传统；
- David Allen：两分钟原则原本处理可在两分钟完成的事项，Clear 的 gateway 用法需区分；
- 行为治疗/成瘾治疗：由受训专业人员实施，不能由本 Skill 替代。

## 11. 最低伦理标准

- 用户决定目标；
- 不使用羞辱、欺骗或未同意的操纵；
- 不把生产力置于健康和安全之上；
- 不承诺结果；
- 不出售“科学”权威；
- 明确哪些建议来自作者、研究或本 Skill。
