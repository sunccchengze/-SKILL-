# 04｜环境、线索与摩擦设计

## 1. 行为地图

在修改环境前，画出现有路径：

```text
进入情境
→ 看见/想起线索
→ 取得工具
→ 开始第一步
→ 完成关键动作
→ 得到即时反馈
→ 收尾/为下次准备
```

为每一箭头标：步骤数、等待、选择、登录、社交风险、体力/认知负担。

## 2. 好习惯的四类设计

### 线索可见

- 将论文和问题模板在午饭前打开；
- 运动鞋放在离门最近的固定位置；
- 用药提醒与药盒放在医嘱允许、安全且实际经过的位置。

可见不等于无限提醒。一个与自然情境绑定的清晰线索通常优于十个通知。

### 路径缩短

- 前一晚准备工具；
- 保存固定模板与文件入口；
- 将标准动作拆为第一步；
- 降低不必要登录/切换。

### 默认值

- 会议默认 25/50 分钟，为记录留空间；
- 打开浏览器默认进入任务页而非信息流；
- 预先选择训练日的安全方案。

默认必须保留用户知情选择，不能用于操纵他人。

### 即时反馈

- 写下一个真实产物；
- 可视化完成而不夸大；
- 为下一次准备工具，使当下行为马上降低未来摩擦。

## 3. 减少坏习惯的四类设计

- **移除/隔离线索**：通知关闭、设备移位、避开高风险路径；
- **增加步骤**：退出登录、移除快捷入口、预先承诺；
- **延迟反应**：先做 60 秒替代和重新选择，不把延迟当绝对禁令；
- **替代功能**：原行为若提供安抚/社交/刺激，替代行为需满足相近即时功能。

对涉及安全、医疗或照护的设备不能粗暴移除。

## 4. 摩擦预算

不是越容易越好。低摩擦可能帮助好行为启动，也可能降低必要质量控制。

| 场景 | 应降低摩擦 | 应保留/增加摩擦 |
|---|---|---|
| 打开写作草稿 | 是 | 提交前保留核验 |
| 记录灵感 | 是 | 公开发布前保留编辑 |
| 保存数据 | 自动备份 | 删除/覆盖增加确认 |
| 用药 | 依医嘱简化 | 剂量变化必须专业确认 |
| 购买 | 必需品可简化 | 冲动高额消费增加等待 |

## 5. 实施意图

研究传统的核心形式是把一个未来情境和一个反应预先连接：

```text
如果/当 [可识别情境]，那么我会 [具体行为]。
```

质量检查：

- 情境是否客观可识别？
- 出现频率是否匹配目标频率？
- 行为是否在当时可行？
- 同一线索是否绑定过多竞争反应？
- 用户对目标是否仍有承诺？

Gollwitzer & Sheeran 的元分析给出总体正效果，但具体领域、计划格式和动机存在异质性。不要对个人承诺 d=.65 的效果。

## 6. 习惯叠加

选择锚点：

- 已经稳定；
- 与新行为地点接近；
- 完成边界清楚；
- 在目标日都会出现；
- 不依赖高度波动情绪。

反例：“在忙完后阅读”——“忙完”边界不清。
较好：“午饭餐盘放回后，坐到书桌时打开论文。”

## 7. 情境变化

### 迁移前

- 列旧锚点与工具位置；
- 识别哪些在新情境消失；
- 为新地点选对应锚点；
- 暂时缩至最低版。

### 迁移后

- 一周内优先重复，不急于扩量；
- 记录旧坏习惯是否由熟悉线索回归；
- 新锚点不稳定时主动更换，不把失败归咎身份。

## 8. 结构性边界

环境设计经常被个人化，但用户可能无法控制：

- 值班、噪音、拥挤住房；
- 管理者安排和算法通知；
- 照护责任、经济约束；
- 残障、慢性病和药物副作用；
- 不安全关系。

此时建议应包括合理便利、组织协商、资源连接或降低目标，不把“收拾桌面”当万能答案。
