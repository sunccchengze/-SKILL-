## 使用顺序

1. 先在 `claim-layer-map.md` 判断声明层级；
2. 到 `source-notes.md` 检查证据能支持什么、不能支持什么；
3. 只打开与当前目标相关的研究笔记；
4. 用 `templates.md` 或 `../scripts/design_habit.py` 生成可执行初稿；
5. 以 7–14 天短周期观察，不把周期说成形成期限。

## 最小披露规则

回答用户时无需倾倒全部研究，但涉及形成时长、自动性、实施意图、身份因果或临床风险时，必须说明关键限定。作者营销语言不能代替效果证据，D1 模板不能伪装成书中原章。
