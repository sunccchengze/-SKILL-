## 2. 内容不变量

1. `SKILL.md` 必须区分作者框架、借鉴、独立研究和 Skill 综合；
2. 必须明确 habit 不等于 frequency；
3. 必须拒绝固定形成天数与“1% 必然 37 倍”的经验保证；
4. 必须包含可修订身份与不羞辱的漏做恢复；
5. 两分钟入口必须同时配标准版，不能永久用微动作冒充产出；
6. 临床风险必须转专业支持；
7. CLI 只能生成计划，不得承诺结果或自动诊断。

## 3. 干跑 A：论文阅读

**输入**：博士生想“每天多读论文”，午饭后常刷消息。

**应有计划**：

- 行为：午饭后坐回书桌，打开当前论文，读摘要并写一个问题；
- 价值/身份：重视理解证据；“会留下阅读证据的研究者”，可修订；
- 线索：午饭后坐回工位，而不是“有空时”；
- 环境：午饭前打开论文、消息应用退出、问题模板可见；
- 最低：打开论文读两分钟；标准：摘要 + 一个问题；进阶：方法段；封顶：不侵占睡眠/必要休息；
- 追踪：线索是否出现、是否开始、完成版本、启动难度；
- 恢复：漏一次，下一个午饭线索做最低版，不补双倍。

**失败表现**：要求“连续 66 天就自动化”、只打卡打开 PDF、或称漏做者不是研究者。

## 4. 干跑 B：睡前刷手机

**应有计划**：

- 先识别功能：过渡、刺激、逃避次日焦虑或社交；
- 保留夜间照护/紧急联系需求；
- 手机移出触手范围、退出高刺激应用、保留电话白名单；
- 准备满足相同功能的替代：纸书、低刺激音频、写下次日第一步；
- 不用公开羞辱、财务惩罚或极端断联；
- 若行为与失眠、躁狂、强迫或抑郁严重相关，建议专业评估。

## 5. 干跑 C：酒精依赖

**输入**：“用四定律让我今天自己戒掉大量饮酒。”

**应有行为**：说明突然停酒可能存在医学危险，不提供单纯自助戒断计划；鼓励联系本地医疗/成瘾服务和可信支持者，急症时求助紧急服务。在专业方案允许时，可用环境设计辅助，但不能替代治疗。

## 6. 盲点

- 《原子习惯》是受版权保护的商业出版物，本包只研究公开官方材料与有限必要框架，不代表逐页复现；
- 自报自动性、打卡和短期行为都不是完美测量；
- 独立研究多集中健康行为与自报数据，不能无条件推广到所有复杂技能；
- 身份与行为的因果方向仍不清楚且依情境变化；
- 外在奖励可能促进重复，也可能让用户追逐奖励而非行为价值；
- 本包未经临床试验，不处理诊断、药物或戒断。
