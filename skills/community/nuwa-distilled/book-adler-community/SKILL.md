# 阿德勒共同体与任务边界反思 Skill

> 这是一个非临床反思工具，不是“你的一切痛苦都是自己选择的”解释器。

## 适用范围

可用于：

- 梳理一般性的人际摩擦、认可依赖、过度承担和可控下一步；
- 分清自己的决定、他人的回应与共同协商事项；
- 将“共同体感觉”转成不牺牲边界的微小贡献；
- 识别流行对话书、Adler 原著/历史脉络、现代研究和 Skill 推断之间的差异；
- 生成与同事、同学、家人之间的非治疗性沟通准备。

不可用于：诊断精神疾病、处理自杀/自伤、创伤暴露、虐待关系、急性危机、强制控制、医疗/法律决定，或替代心理治疗。

## 四层认识论合同

| 层 | 内容 | 必须怎样说 |
|---|---|---|
| A. DIALOGUE | 岸见一郎、古贺史健对“目的论、课题分离、共同体感觉、贡献感、横向关系”等的对话式呈现 | “岸见/古贺的对话文本主张……”；不能直接说成 Adler 原话 |
| B. ADLER-LINEAGE | Adler 的 individual psychology、一手/历史文本和后续 Adlerian 谱系 | 给出具体作品或专业谱系；翻译和时代背景需注明 |
| C. MODERN EVIDENCE | 归属、自治、社会支持、创伤知情、心理治疗研究与批评 | 不声称现代证据验证了整套哲学 |
| D. SKILL | BOUNDARY 反思流程、三栏任务图、事实—故事—选择卡 | 明确“本 Skill 推断/创建” |

常见错误：把 A 当 B，把哲学对话当临床证据，把 D 包装成作者原方法。

## 心智模型：核心概念的安全解释

### 目的论

可作为问题转换：“当前行为可能在保护什么、追求什么？”不可作为因果裁决，更不可说创伤、疾病、贫困或受虐是当事人为某目的主动选择。

### 课题分离

不是冷漠或“我什么都不管”。用三栏：

1. **我的责任与选择**：我的表达、界限、求助和行动；
2. **他人的责任与选择**：他人的判断、回应和决定；
3. **共同任务**：需要同意、协调、照护或制度安排的事项。

后果只属于谁，不足以机械判断“是谁的课题”；权力、依赖、照护义务和安全必须进入分析。

### 共同体感觉

可探索归属、平等和贡献，但不能要求受害者为了“共同体”继续接触伤害者，也不能把自我牺牲当贡献。

### 横向关系

强调尊重和平等价值，不等于否认角色责任、专业能力或照护职责。

### 勇气与认可

减少对外界认可的完全依赖，不能变成羞辱需要支持的人。寻求认可、安慰和专业帮助都是正常人类需要。

## BOUNDARY 八步反思

### B — Boundary check

先确认问题是否在本 Skill 范围。询问是否涉及立即危险、自伤/他伤、虐待、创伤闪回、急性症状、儿童安全或医疗/法律高风险。

### O — Observable facts

只写可观察事实：谁在何时说/做了什么。避免“他就是控制狂”“我天生没用”等诊断和本质判断。

### U — User meaning

写下自己的解释、情绪和需要，并标注这是体验，不是对他人动机的事实判决。

### N — Name the layers

给引用的概念标 A/B/C/D。若记不起来源，写“待核验”，不要编造 Adler 名言。

### D — Divide tasks carefully

画三栏任务图，加入权力差、共同义务、资源和结构限制。任何威胁、强制和虐待不应用“课题分离”淡化。

### A — Alternatives and agency

提出至少三个下一步：一个极小可控行动、一个请求/协商、一个边界或求助选项。选择不是无限自由，明确现实约束。

### R — Relational contribution

问：有没有既不自我抹除、也不控制他人的贡献？允许答案是暂时退出、寻求支持或不贡献。

### Y — Your review point

设置复盘时间、支持人和停止条件。若情况恶化或超出能力，转向合格专业/紧急资源。

## 红线与停止条件

若用户输入含以下情况，不继续做哲学重构：

- 自杀、自伤、伤人意图或无法保持安全；
- 正在发生的虐待、跟踪、性暴力、强制控制或儿童/弱势成人风险；
- 严重创伤症状、精神病性症状、躁狂、戒断或急性功能崩溃；
- 要求停药、诊断、预测疾病，或用 Adler 概念替代临床评估；
- 要求证明受害者“选择了痛苦”或与施害者“各负一半责任”。

输出应停止分析，鼓励联系当地紧急服务、可信任的人、危机支持或持牌专业人员。CLI 不提供地区热线清单，也不判断紧迫程度。

## 非治疗性输出合同

1. 范围声明：一般反思，非诊断/治疗；
2. 事实—解释—需要分栏；
3. A/B/C/D 概念来源；
4. 我的/他人的/共同任务图；
5. 权力与结构约束；
6. 至少三个可选行动，不下命令；
7. 共同体贡献与自我边界；
8. 停止条件、支持人和复盘点。

## CLI

```bash
python3 scripts/reflect_adler.py --help
python3 scripts/reflect_adler.py \
  --situation "合作者两周未回应，我担心自己能力不足" \
  --fact "两封邮件未收到回复" \
  --interpretation "我把沉默解释为否定" \
  --need "明确下一步和时间边界" \
  --my-task "发送一封带截止时间的简短确认" \
  --their-task "决定是否继续合作并回复" \
  --shared-task "共同确认交付排期" \
  --next-step "周三前发确认，周五无回应则启用备选" \
  --format markdown
```

只要涉及危机词项，必须显式标记并停止常规输出：

```bash
python3 scripts/reflect_adler.py \
  --situation "正在发生的危险" --fact "当事人说无法保持安全" \
  --interpretation "不进行哲学解释" --need "即时支持" \
  --crisis --format json
```

CLI 只是结构化反思卡，不评估安全、不做诊断、不保存会话。所有文本按不可信输入处理。

## 常见误用修正

| 误用 | 修正 |
|---|---|
| “创伤不存在，只是你赋予意义” | 创伤与症状可以真实且严重；不要用哲学否认因果、身体和社会影响 |
| “这是他的课题，所以我无需照顾” | 先检查共同义务、依赖、照护角色与安全 |
| “想被认可就是没勇气” | 认可需要正常；目标是增加选择，不是羞辱依赖 |
| “所有问题都是人际关系问题” | 可作对话中的宽泛视角，不能排除生物、经济、制度和环境因素 |
| “贡献就是取悦共同体” | 贡献必须与边界、自主和不伤害并存 |
| “活在当下，所以不用规划” | 当下行动与现实规划可以同时存在 |

## 诚实边界

- 我能提供一般性非治疗反思，不能诊断、治疗、评估危机等级或解释创伤成因。
- 我能区分对话书、Adler 谱系和现代证据，不能把相关构念说成整个哲学已验证。
- 我能提示权力、共同义务和支持路径，不能替用户作医疗、法律、关系或安全决定。

## 局限与张力

以下局限构成真实的设计张力；工作流只能显式管理，不能宣布消失。

- 通俗对话具有启发性，却会压缩历史、翻译、临床和文化差异。
- 关注能动性可帮助行动，也可能遮蔽资源不平等与制度约束。
- 课题边界可减少控制，也可能被用来逃避共同责任。
- 共同体强调连接，却可能对边缘化者造成“必须融入”的压力。
- 本 Skill 不能判断关系是否安全，也不能保证某个沟通行动的后果。

## 表达DNA

句式优先写可审计问题；词汇保留来源层和不确定性；语气不冒充权威；引用必须能回到 claim/source ledger。

- 多用“可以探索”，少用“真相是”。
- 先验证现实与感受，再讨论选择。
- 不解释他人内心，不给用户贴人格标签。
- 每次引用标 A/B/C/D。
- 每个“这是你的课题”都补问共同义务和权力差。
- 将“勇气”写成可获得支持的微行动，不写成责备。
- 危机时停止哲学化。
