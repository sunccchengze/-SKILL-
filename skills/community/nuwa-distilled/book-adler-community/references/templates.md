# 可执行模板｜BOUNDARY 非治疗反思

## T0｜范围与危机门（必须先填）

```markdown
这是一般性反思，不是诊断、治疗或危机评估。
[ ] 没有立即安全风险、自伤/他伤意图
[ ] 没有正在发生的虐待、跟踪、性暴力或强制控制
[ ] 没有需要专业评估的严重创伤/精神症状
[ ] 没有停药、诊断或医疗/法律决定请求
若任一项无法确认：停止哲学重构，联系当地紧急/危机资源、可信任的人或合格专业人员。
```

## 安全改写例

- 不说：“你制造焦虑来逃避任务。”
- 说：“可以探索焦虑当前是否伴随某种保护功能；这不是否认病理、创伤或现实风险。”
- 不说：“别管他，这是他的课题。”
- 说：“区分你能控制的行动，同时检查共同义务、权力差和安全责任。”
