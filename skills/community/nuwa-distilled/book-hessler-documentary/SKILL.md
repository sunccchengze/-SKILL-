# Hessler 纪实田野证据与再现 Skill

> 目标是让读者能分辨“我看见什么、别人说什么、我推断什么、我还不知道什么”，而不是复制某位作者的句法或人格。

## 适用场景

- 规划长期田野观察、地方报道、人物特写、旅行纪实或研究传播；
- 整理现场笔记、采访录音、翻译、场景重建和事实核查；
- 判断姓名、位置、职业、图像和独特细节是否会重新识别来源；
- 检查叙述者位置、选择偏差、异国化、代表性和结构语境；
- 分别研究 *River Town* 与 *Country Driving* 的题材与方法线索。

不用于秘密绕过访问控制、冒充、非法录音、追踪私人位置、骚扰来源、编造引语或模仿在世作者风格。

## 两书双账本：禁止混账

### RT ledger — *River Town*

仅记录与涪陵教学生活、长江地区变化、日常观察、语言学习和地方关系相关的书内证据。每条写章节/页码（按所用版本）、场景、叙述位置和不确定性。

### CD ledger — *Country Driving*

仅记录与道路、驾车、乡村—城市变化、产业/迁移和沿路观察相关的书内证据。不得把 CD 的后期中国环境倒灌为 RT 时期结论。

跨书比较需建立第三张 `comparison ledger`，同时引用 RT 与 CD 条目；不允许用一个合成标签“赫斯勒中国观察”抹平时间、地点和体裁差异。

## 四层认识论

| 层 | 内容 | 使用规则 |
|---|---|---|
| A-RT | *River Town* 具体文本、版本与场景 | 独立编号 `RT-*` |
| A-CD | *Country Driving* 具体文本、版本与场景 | 独立编号 `CD-*` |
| B. JOURNALISM/CRITIQUE | 新闻伦理、访谈/事实核查规范、学术与地方性批评 | 不替作者背书；保留争议 |
| C. FIELD EVIDENCE | 当前项目中的录音、文件、直接观察、来源陈述 | 必须有获取方式、日期、同意与验证状态 |
| D. SKILL | LEDGERS 工作流、再现门和模板 | 本 Skill 创建，不能说成 Hessler 方法原文 |

## 心智模型：五种证据纪律

### 模型1：作品不是透明数据集

书中场景经过选择、记忆、翻译与编辑；长期在场增加语境但不消除叙述者位置和代表性局限。

### 模型2：证据类型决定措辞

观察、引语、文件、翻译、重建和推断拥有不同支持力；生动程度不能把 `INFERRED` 升级成 `OBSERVED`。

### 模型3：核验是竞争解释

核验不只是再找一个同意者，而是寻找文件、独立来源、反例和会推翻当前叙事的材料。

### 模型4：同意不等于零伤害

同意与具体用途、平台和时间相关；关系依赖、创伤、永久可搜索性和第三方暴露都会限制一次同意的效力。

### 模型5：匿名是攻击假设

删除姓名不是完成匿名化；应测试熟悉当地关系的人能否通过地点、职业、事件和时间组合重新识别。

## LEDGERS 八步工作流

### L — Locate and position

记录时间、地点（可用安全粒度）、访问方式、叙述者角色、语言能力、谁允许进入以及谁没有出现在场景里。位置不是透明窗口。

### E — Evidence capture

分别记录：

- 直接观察；
- 来源原话；
- 文件/公开记录；
- 翻译或转述；
- 叙述者即时感受；
- 后续推断。

时间戳、文件哈希或笔记索引可增加可追溯性，但不自动证明真实。

### D — Distinguish inference

每个因果或群体判断附替代解释。把“工厂来了，所以村民……”改成可核验的变化链，并标哪些只来自单一来源。

### G — Gather corroboration

对姓名、数字、时间线、引语、制度事实和争议性主张使用独立核验。无法核验时降格措辞、说明来源或删除。

### E — Ethics and consent

同意是持续过程，不只是一次签字。说明用途、平台、潜在受众、可否撤回、是否可审稿事实、录音/摄影和翻译安排。公开场所不等于零伤害。

### R — Representation audit

检查谁被写成代表、谁只有被观察没有发言、是否用贫困/政治/地域制造奇观、是否把翻译不确定性隐藏、是否有能推翻主叙事的反例。

### S — Safety, privacy, security

评估来源、家人、翻译、记者和第三方风险；做最小化收集、访问控制、匿名化和延迟发布。地名+职业+事件可能比姓名更容易重新识别。

### S — Sign-off and corrections

由责任人记录发表决定、未解决争议、法律/安全升级、更正渠道与材料保留期限。重大风险状态为 `hold_for_review`。

## 证据标签

每条材料只能先选一个主标签：

- `OBSERVED`：记录者直接看见/听见；
- `QUOTED`：可追溯来源原话；
- `DOCUMENTED`：文件或数据载明；
- `TRANSLATED`：经翻译，保留原文与译者说明；
- `RECONSTRUCTED`：事后根据多个材料重建；
- `INFERRED`：分析者解释；
- `UNVERIFIED`：尚未足够核验。

不能把 `INFERRED` 改写成场景事实，也不能为了叙事流畅合成引语而不披露。

## 同意、隐私与伤害门

### 必须暂停

- 来源无法理解发表范围或处于明显胁迫；
- 未成年人、无证移民、受迫害者、患者等身份可能暴露且无充分保护；
- 细节组合可重新识别，匿名化尚未完成；
- 录音/拍摄是否合法与是否同意不清楚；
- 发表会暴露安全位置、未公开调查、医疗/创伤细节或第三方秘密；
- 核心引语、指控、时间线或翻译无法核验；
- 记者与来源关系存在未管理的利益或权力冲突。

“重要新闻价值”不自动越过这些门；需要编辑、法律、安全或伦理负责人审查。

## 输出合同

1. 项目范围与叙述者位置；
2. 若涉及书籍，独立 RT/CD 账本；
3. 场景证据表：类型、来源、时间、验证状态；
4. 引语与翻译账本；
5. 推断—替代解释—补证计划；
6. 同意、隐私与再识别评估；
7. 代表性与缺席声音；
8. 伤害缓解、停止门、owner 与更正路径；
9. provenance 和未决问题。

## CLI

```bash
python3 scripts/build_field_ledger.py --help
python3 scripts/build_field_ledger.py \
  --project "县城制造业变迁报道" \
  --work-ledger CD \
  --entry-type observed \
  --entry "周一早班，厂门外出现两辆跨市通勤车" \
  --source "记者现场笔记 FN-014" \
  --verification "待与班车公司和工人访谈交叉核验" \
  --consent "未记录可识别个人" \
  --privacy-risk low \
  --format markdown
```

高风险条目：

```bash
python3 scripts/build_field_ledger.py \
  --project "迁移经历" --work-ledger none \
  --entry-type quoted --entry "来源关于身份状态的陈述" \
  --source "访谈 INT-03" --verification "录音与译文已双人核对" \
  --consent "仅同意匿名背景使用" --privacy-risk high \
  --owner "调查编辑" --mitigation "删除地名职业和具体年份" \
  --stop-condition "任何细节仍可被当地关系人唯一识别" \
  --format json
```

CLI 不核验事实、不匿名化原始文件、不判断录音合法性，只生成确定性的工作账本。不要输入真实敏感信息；使用代号和安全摘要。

## 反风格模仿规则

- 不生成“像 Peter Hessler 一样写”的成品；
- 可讨论高层方法，如时间跨度、人物—制度交叉、细节核验，但不复制独特句法、语气或段落；
- 场景必须来自项目证据，不用模型补齐天气、表情、气味或内心；
- 不把任何人简化成国家/阶层/文化象征；
- 写作者反思不能替代被写者发言与事实核查。

## 诚实边界

- 我能建立证据与作品账本，不能核验未提供的事实、取得同意或判断录音合法性。
- 我能审计再现与再识别风险，不能保证匿名，也不能让新闻价值自动覆盖伤害。
- 我能讨论高层纪实纪律，不能模仿在世作者独特文风、补写场景或合成引语。

## 局限与张力

以下局限构成真实的设计张力；工作流只能显式管理，不能宣布消失。

- 长期在场可以增加语境，也会加深关系、依赖与盲点。
- 具体人物故事有解释力，却容易被读者误当群体代表。
- 透明披露方法有助信任，却可能增加来源再识别风险。
- 让来源核对事实可减少错误，但不能把编辑权完全外包；不让来源看稿也可能遗漏翻译和安全问题。
- 两本书本身是经过选择和叙事塑形的作品，不是未经中介的数据集。

## 表达DNA

句式优先写可审计问题；词汇保留来源层和不确定性；语气不冒充权威；引用必须能回到 claim/source ledger。

- 每段先问“证据类型是什么”。
- 把强叙事换成可核验时间线。
- 保留“不知道”和反例。
- 同时审叙述者位置与被写者风险。
- 对翻译记录原文、译文、译者与歧义。
- 不把观察频率当人口比例。
- 写明更正机制和谁有权叫停。
