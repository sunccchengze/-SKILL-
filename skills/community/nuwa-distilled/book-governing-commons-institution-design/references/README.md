# Governing the Commons / COMMONS references

- [`claim-layer-map.md`](claim-layer-map.md)：每个核心 claim 的唯一 ID、A/B/C/D 层、source IDs 和禁止坍缩。
- [`source-notes.md`](source-notes.md)：来源身份、版本、supports、does-not-support、证据级、冲突、限制、未决。
- [`templates.md`](templates.md)：只属于本书对象的可执行制品。
- [`research/`](research/)：六轮研究；每轮必须留下 workflow decision / failure gate / unresolved。

## 最小披露

任何输出至少带：`claim IDs`、`source IDs`、`layer`、`edition/version`、`assumptions or contested norms`、`unvalidated`、`owner/status`。没有真实 locator 的用户材料只能标 `submitted_not_verified`。分析结果不得改写成部署、认证、法律、临床、人事或制度正当性批准。
