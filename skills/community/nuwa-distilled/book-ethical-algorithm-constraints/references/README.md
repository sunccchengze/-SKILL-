## A/B/C/D 规则

- **A**：原作可定位主张；
- **B**：原作自己的限定、范围与成熟度说明；
- **C**：独立支持、反证、不可能性或治理证据；
- **D**：本 Skill 的操作综合，引用栏必须明确“本 Skill”。

A/B/C 不因被纳入就都为真；来源卡写适用范围。D 不得倒灌为作者原话。网页检索日统一记录为 2026-08-16；动态网页后续使用须重查。

## 证据强度

优先顺序不是简单排名：官方书页/原作负责版本与作者主张；同行评审原始研究负责特定实证或定理；标准/监管文本负责制度要求；批评负责盲区。任何来源只能承载其设计与范围内的结论。

## 引用要求

输出至少含 claim ID、source ID、版本/发布日期（可得时）、适用人群/地域/任务、关键限制。禁止只列 URL 不说明支持关系。
