# Research Pass — 原作结构与形式化议程

## 目标

确认 2019 OUP 书目和五章结构，并把作者 formalization agenda 与独立 theorem、治理批评及本 Skill gate 分开。

## 输入与方法

EA01 出版社负责书目/目录，EA02 作者 ACM 文章负责研究议程；EA15/EA16 负责独立形式化批评。没有把后来的批评伪装成作者自述。

## 主要发现

原作连接 privacy、fairness、strategic behavior、adaptive analysis 与伦理算法前景。作者承认 privacy 技术成熟度高于 fairness/explainability。形式化可提高 precision/enforceability，但 object selection 和 institutional power 留在公式外。A-ETH/B-ETH 因此分层。

## 反证与边界

出版社简介不是论证；“可计算”不等于价值已正确翻译。2026 新综述也需随学界更新，不能作为形式方法全盘无效的证据。

## 设计决议

CONSTRAIN-ACT 决定先做 context/rights/harm，再 formal property；每项翻译记录保留、丢失、authority 与 dissent。

## 纳入产物

本轮进入 `SKILL.md` 的 CONSTRAIN-ACT 步骤/停止门、`source-notes.md` 的来源卡、`claim-layer-map.md` 的对应 claim、`templates.md` 的强制字段，并至少由一个 adversarial test 或仓库集成断言约束。没有把研究日志当引用终点；最终输出仍须回链原始 source ID。

## 未解决

- 用户场景的本地数据、组织记录、受影响人证据和合法 authority 尚未知；不能由本轮桌面研究代填。
- 动态网页、软件、法律与在线书版本会变化；复用时重查基准日并记录差异。
- 形式字段可能被合规表演式填写；需要独立复核、反证、minority report 和可执行 stop/rollback。
