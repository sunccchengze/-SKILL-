# Research Pass — 公平不可能性与 subgroup auditing

## 目标

把“公平不可能”口号还原为特定定义/假设，并确定 metric 选择、base rate、label validity、subgroup 与 remedy 的决议流程。

## 输入与方法

读取 EA06/E07 incompatibility、EA08 fairness gerrymandering、EA09 disparate impact 与 EA10 abstraction traps。定理、法律分析和社会技术批评分别记录。

## 主要发现

differing base rates 与非完美预测下，calibration 和部分 error parity 不能兼得；这不涵盖所有 fairness。大组 parity 会藏交叉 subgroup violation，而丰富搜索增加 sample、multiplicity、privacy 和计算负担。C-ETH-02/C-ETH-03 形成。

## 反证与边界

base rate 也可能由不平等制度和 label bias 产生；简单匹配 metric 不说明 harm 减少。abstention/coverage 可伪装改善。定理不能选择哪项权利优先。

## 设计决议

模板从 harm pathway 映射 metric，要求 definition/denominator/uncertainty/label history。冲突输出 TRADEOFF_DECISION_REQUIRED，记录合法 authority、dissent 与 remedy。

## 纳入产物

本轮进入 `SKILL.md` 的 CONSTRAIN-ACT 步骤/停止门、`source-notes.md` 的来源卡、`claim-layer-map.md` 的对应 claim、`templates.md` 的强制字段，并至少由一个 adversarial test 或仓库集成断言约束。没有把研究日志当引用终点；最终输出仍须回链原始 source ID。

## 未解决

- 用户场景的本地数据、组织记录、受影响人证据和合法 authority 尚未知；不能由本轮桌面研究代填。
- 动态网页、软件、法律与在线书版本会变化；复用时重查基准日并记录差异。
- 形式字段可能被合规表演式填写；需要独立复核、反证、minority report 和可执行 stop/rollback。
