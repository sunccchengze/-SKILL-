## 3. 发现的内部矛盾

### A. ID、标题和日期错位

最初清单把 `N270`—`N299` 配到一组标题和日期；后续“详细提取”又用相同 ID 指代另一组标题和日期。`N289` 也出现互不兼容的标题/日期。后续详细内容不能自动并到原清单行。

处理：

- `N270`—`N272` 按后续审计明确排除；
- `N273`—`N299` 只保存最初清单元数据；
- 后续错位摘要全部隔离，不生成 Zoey 知识点，等待规范链接或真实 note ID 重映射。

### B. 缺失详情数量冲突

一处称 `N234`—`N243` 共 10 条缺详情；另一处把 `N234`—`N240` 说成 7 条。收到的 60 行又从 `N240` 开始，仅重叠四条。

处理：`N240`—`N243` 即使在早先文本中出现过摘要，也全部降为元数据、禁止支持知识点，等待重提取。

### C. 覆盖率冲突

“50 条完整 + 7 条部分 = 57”的说法，与“10 条缺详情”以及后续错位记录不能同时成立。报告中的 `87.7%` 不可复算为可靠覆盖率。

处理：不采纳该覆盖率；改用本文件的互斥状态计数。

### D. 置顶状态冲突

导出的不同区段给出了不一致的置顶标题与日期。

处理：所有来源的 `pinned` 暂记为 `null`，`pin_status=not_reliably_resolved`。

### E. URL 与 note ID 未证实

`N240` 等看起来是导出定位符，不是已证实的小红书规范 note ID；`https://www.xiaohongshu.com/explore/N240` 等 URL 也没有经过可访问性验证。

处理：保留原样仅为导入追踪，字段标记 `url_status=unverified_export_url`；回答时不得写成“已验证原帖链接”。

### F. 二次综合混合了观点和分析

导出末尾的四条主线——科研者自我校准、系统学术训练、权力不对称中的导师/课题组策略、人类与 AI 判断边界——具有研究价值，但属于点点或整理者的跨帖综合，不是 Zoey 的逐字陈述。

处理：只把能回链到合格来源的内容写入 `claims.jsonl`；跨帖结论标 `synthesis`，其余仅进入研究备忘。
