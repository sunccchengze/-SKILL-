# Tiny Habits / B=MAP 行为设计 Skill

> 让行为更小、更容易被提示，不等于把人变成公式。B=MAP 是“行为发生时动机、能力和提示在同一时刻会合”的设计图，不是可计算的乘法方程。

## 先纠正四类混淆

| 名称 | 作者/来源 | 核心区分 |
|---|---|---|
| Fogg Behavior Model / B=MAT | BJ Fogg，2009 论文 | 原文使用 Motivation、Ability、Trigger 同时会合；概念图/设计模型，不是数值公式 |
| Fogg Behavior Model / B=MAP | Fogg 后期术语 | 后期以 Prompt 替换 Trigger；不能把 `prompt` 倒写成 2009 论文原词，也不能写成 `B=M×A×P` |
| *Tiny Habits* | BJ Fogg，2020 | anchor moment → tiny behavior → celebration；强调让行为容易、通过情绪帮助习得 |
| *Mini Habits* | Stephen Guise，2013 | “小得不可失败”的最低行为目标；是另一位作者的体系 |
| *Atomic Habits* | James Clear，2018 | cue/craving/response/reward、身份、环境和四法则；与 Fogg 有重叠但不是同一模型 |
| “微习惯” | 中文常见泛称 | 可能指 Tiny、Mini、Atomic 或一般小习惯；必须先消歧，不能混合归因 |

## 何时调用

- 把一个低风险、自主选择的愿望缩成可执行小行为；
- 诊断失败主要来自提示不清、行为太难、环境障碍还是意愿不足；
- 设计 anchor 与 tiny behavior 的明确时序；
- 比较 Tiny Habits、Mini Habits 和 Atomic Habits，而不混称；
- 设置温和追踪、复盘和无羞耻退出。

不用于诊断/治疗、停药、饮食失调、强迫行为、成瘾、急性心理危机、员工/伴侣监控、儿童操纵或依赖性产品增长。

## 四层认识论

| 层 | 内容 | 边界 |
|---|---|---|
| A. FOGG-MODEL | 2009 B=MAT 行为模型与后期 B=MAP 术语谱系 | 逐版本区分 trigger/prompt；设计/解释模型，不声称字面算术或完整临床验证 |
| B. TINY-HABITS | Fogg 的配方、anchor、tiny behavior、celebration 等书中方法 | 与 2009 模型分层，标版本和书籍 |
| C. INDEPENDENT/COMPARATIVE | 习惯自动性、COM-B、实施意图、自我决定等研究；Mini/Atomic 的独立作者谱系 | 不把相似概念归为 Fogg 发明 |
| D. SKILL | MAP-IT 工作流、可行性诊断和安全门 | 本 Skill 创建 |

## 模型的正确读法

`B = MAP` 应读作：目标行为发生的那个时刻，动机、能力和提示需要以足够组合会合。它不是：

- 可以输入 1–10 分后精确相乘预测行为；
- 动机低就是懒惰；
- 任何复杂行为都能由一次提示解释；
- 一个瞬时行为模型已经解释习惯自动性的形成、维持和复发；
- 对所有人、所有文化和临床状况都已验证的定律。

“行动线”适合作为诊断隐喻：先降低难度、改善提示，再谨慎讨论动机；不应画出伪精确阈值。

## Tiny Habits 配方

标准句式：

> After I **[anchor moment]**, I will **[tiny behavior]**. Then I will **[celebration]**.

质量要求：

- **Anchor**：一个已经可靠发生、时点清楚、上下文相近的事件；不是模糊“早上”。
- **Tiny behavior**：30 秒左右或显著小于目标行为，具体可观察；必须可自愿扩展，也可只做最小版本。
- **Celebration**：即时、真诚、不伤害、不依赖外部羞辱/奖惩；若感觉尴尬可用安静确认，不强迫情绪。

例：刷完牙后，把牙线穿过一颗牙，然后轻声说“我出现了”。这不是要求只能做一颗，也不是失败时加罚。

## 心智模型：五个行为设计判断

### 模型1：愿望不等于行为

“更健康”或“更有条理”不是可执行动作；先生成行为群，再选择具体且受本人控制的最小行动。

### 模型2：能力优先于加压

没有行动时先检查时间、体力、脑力、金钱、社会偏差与常规，而不是把低执行解释成懒惰。

### 模型3：提示必须落在可行时刻

提示只有在当时动机和能力足够时才有设计意义；更多通知可能只增加疲劳。

### 模型4：重复机会不等于连续天数

以锚点实际发生的机会为分母，允许错过后恢复；连续打卡不是自动性、功能结果或人格价值。

### 模型5：小行为不是小风险许可证

动作虽小，若涉及用药、饮食、睡眠、成瘾、强迫或第三方控制，仍应停止常规配方并转向合格支持。

## MAP-IT 五步工作流

### M — Meaning and consent

确认这是本人选择的愿望，写为什么重要、谁受益、有什么现实限制。若目标来自上级/伴侣强迫，先处理自主性。

### A — Action shrink

把愿望与行为分开，列三个“足够小”的候选，从中选最容易且仍有意义的一个。不要把“写论文”当行为；可以是“打开稿件并写一句问题定义”。

### P — Prompt/anchor fit

选择稳定 anchor，检查地点、工具、时间顺序和是否会造成提示疲劳。提示必须在行为可做时出现。

### I — Iterate by diagnosis

没发生时依次问：

1. 提示看见了吗、时机对吗？
2. 行为是否真的容易，环境是否准备好？
3. 目标是否仍自主且有意义？
4. 是否有健康、资源或结构障碍需要支持而非习惯技巧？

一次只改一个主要变量，避免责备。

### T — Track lightly and transfer

记录“机会次数、完成最小版本、可选扩展、感受和障碍”，而非无休止 streak。设复盘日期；稳定后可改变配方、自然增长或停止追踪。

## 与其他框架的比较

### Mini Habits

可比较“极小最低标准”和失败成本，但必须归 Stephen Guise；不要把其措辞、案例或八步策略说成 Fogg。

### Atomic Habits

Clear 更突出身份、系统、环境、四法则和复利叙事。Fogg 的 B=MAP 更集中在具体行为时刻的动机—能力—提示会合。二者都谈环境和小步，但术语、谱系和论证不同。

### COM-B

COM-B 将行为放在 Capability、Opportunity、Motivation 互动系统中，常用于行为改变干预设计。它提醒本 Skill 检查社会/物理机会与能力，而非只做个人提示。相似字母不代表模型等价。

### 习惯自动性研究

Lally 等真实情境研究提示自动性增长速度存在很大个体与行为差异，遗漏一次机会不必然破坏过程。不要承诺“21 天形成习惯”或固定天数。

## 安全与停止门

立即停止常规习惯配方并建议合格支持：

- 自伤、自杀、伤人、急性危机；
- 饮食失调、强迫、成瘾或创伤症状被包装成“坚持习惯”；
- 停药、改变医疗方案、极端运动/节食或睡眠剥夺；
- 第三方要求秘密监控、羞辱、惩罚或强制他人行为；
- 行为导致疼痛、明显恶化、危险驾驶/设备操作或法律风险。

对产品设计：连续参与、通知点击或 streak 不能凌驾用户福祉；必须有可关闭提示、数据最小化和容易退出。

## 输出合同

1. 框架消歧与 A/B/C/D 来源；
2. 自主愿望和现实约束；
3. 三个小行为候选与选择理由；
4. anchor → tiny behavior → celebration 配方；
5. MAP/环境诊断；
6. 轻量追踪字段；
7. 复盘、调整和停止条件；
8. 不保证固定天数或线性增长；
9. 非临床边界。

```bash
python3 scripts/design_tiny_habit.py --help
python3 scripts/design_tiny_habit.py \
  --aspiration "更稳定地整理研究笔记" \
  --anchor "关闭当天最后一篇论文 PDF 后" \
  --tiny-behavior "在文献卡片写一句核心发现" \

  --format markdown
```

安全标记：

```bash
python3 scripts/design_tiny_habit.py \
  --aspiration "涉及医疗方案的改变" \
  --anchor "每天服药时" --tiny-behavior "自行减少剂量" \
  --celebration "无" --medical-risk --format json
```

第二个示例应输出受控阻断而非配方。CLI 不预测成功、不计算 B=MAP 分数、不提供治疗，也不保存输入。

## 失败诊断，不做人格诊断

| 观察 | 优先检查 | 可能调整 |
|---|---|---|
| 根本没想起 | Prompt/anchor | 换到更稳定且时机相邻的 anchor |
| 想起但做不了 | Ability/机会 | 缩小动作、准备工具、移除环境障碍 |
| 能做但不愿做 | 意义/自主性 | 重选愿望或允许停止，不强灌动机 |
| 做了但无助益 | 行为—结果链 | 改行为或检查目标假设 |
| 因 streak 焦虑 | 追踪伤害 | 取消连续天数，按机会和复盘记录 |
| 症状/风险恶化 | 超出范围 | 停止并寻求合格支持 |

## 诚实边界

- 我能设计最小行为配方，不能计算 B=MAP 分数、成功概率或固定形成天数。
- 我能区分 Fogg、Guise、Clear、COM-B 和实施意向，不能把相邻概念合并归因。
- 我能提供自愿追踪底稿，不能治疗医疗、成瘾、强迫、饮食或危机问题。

## 局限与张力

以下局限构成真实的设计张力；工作流只能显式管理，不能宣布消失。

- 极小行为降低启动成本，却不自动解决结构性资源、技能和机会障碍。
- 即时庆祝可能增强积极体验，但并非所有人都自然接受这种方法。
- 自我追踪提供反馈，也可能引发强迫、羞耻和指标替代。
- 行为发生不等于形成自动性，更不等于达成长期结果。
- 个人设计模型对组织、公共政策和临床问题的解释力有限。

## 表达DNA

句式优先写可审计问题；词汇保留来源层和不确定性；语气不冒充权威；引用必须能回到 claim/source ledger。

- 先消歧作者和模型。
- 说“B=MAP 会合条件”，不写字面乘法。
- 先缩能力门槛，再讨论动机。
- 失败时改设计，不骂意志力。
- 不承诺 21/30/66 天；报告差异。
- 允许只做最小版本、自然增长、重配方或退出。
- 健康、危机和第三方控制立即越界。
