## T1｜愿望到微行为

```markdown
愿望/结果：
我有直接控制吗：
行为群（列至少 5 个）：
候选微行为：
物理动作是否明确：
最小版本（低能力日仍可做）：
“不做”是否无羞耻/惩罚：
```

## T2｜MAP 诊断（非算术）

| 维度 | 定性证据 | 障碍 | 最小设计改动 | 仍不确定 |
|---|---|---|---|---|
| motivation | 现在为何愿意/不愿意 |  | 不以加压为默认 |  |
| ability | 时间、钱、体力、脑力、社会偏差、常规 |  | 降摩擦/缩小动作 |  |
| prompt | 行动时刻是否已具备 M 与 A |  | 清晰且可关闭 |  |

不得填 0–10 后相乘，不得把 `B = M × A × P` 当预测概率。

## T3｜锚点配方

```markdown
锚点（已有且可靠的具体事件）：在我……之后
新微行为（一次动作）：我会……
即时确认/庆祝（自愿、真实、不尴尬）：
备用锚点：
环境准备：
若错过：跳过并在下一机会重来，不补偿、不羞辱
```

## T4｜七日轻量日志

| 日期 | 锚点发生 | 提示被看见 | 做了最小版 | 做了更多（可选） | 感受 | 障碍/情境 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

这不是“连续打卡”惩罚系统；缺失数据不得自动记为失败。

## T5｜迭代树

```markdown
若锚点没发生 → 换更可靠锚点
若锚点发生但没想起 → 调整提示的时机/可见性
若想起但做不了 → 再缩小或移除能力障碍
若能做但不愿做 → 重选愿望/行为，不用羞耻加压
若稳定且自愿想扩展 → 小幅自然增长；最小版仍算完成
若造成疼痛、强迫、进食/睡眠/用药风险 → 停止并寻求适当专业支持
```

## T6｜评估记录

```markdown
观察窗口：
机会数（锚点发生）：
最小行为完成数：
机会条件完成率（仅描述本窗口）：
错过后的恢复：
主观负担：
功能性结果（不要只报打卡）：
竞争解释（季节、同伴、工具、其他干预）：
决定：keep / shrink / change_anchor / choose_new_behavior / stop
```

## 完成定义

行为具体且很小；提示位于可行时刻；庆祝自愿；记录按机会而非羞耻连续天数；结论不使用“66 天定律”；与 Guise、Clear、COM-B 和实施意向的来源保持分离。
