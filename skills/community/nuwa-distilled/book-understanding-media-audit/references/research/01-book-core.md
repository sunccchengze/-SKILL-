# 01｜1964 原书与核心命题

## 媒介范围

McLuhan 的“媒介”不限新闻、广播或电视，还包括语言、衣服、道路、货币、钟表、电灯等扩展人的技术/形式。使用时不能无限泛化，仍要定义具体配置。

## “媒介即讯息”

官方资料以原书表述解释：媒介的讯息是它引入人类事务中的尺度、速度或模式变化。重点是媒介结构持续塑造行动，即使承载内容更换。

这不表示：

- 内容真假不重要；
- 每种媒介只有一个效果；
- 技术独自决定历史；
- 媒介效果天然大于内容效果且无需验证。

## 内容嵌套

“一种媒介的内容是另一种媒介”鼓励沿承载链追踪。例如 AI 回答以语言为内容，也嵌入检索文档、图像、数据库和排名；每一层有不同选择机制。

## 方法特征

原书常用格言、对比和跨历史“probes”促使读者改变注意。蒸馏时保留其问题生成力，但不能把探索性例子包装成标准化因果定律。

## “媒介”必须操作化到配置

同一个名词可隐藏不同媒介：一款生成模型经 API 自动写报告、在搜索页回答、在 IDE 补全或在客服脚本中建议，输入、默认、节奏、可见性、责任和退出都不同。最小配置记录包括设备/接口、版本、输入输出、检索/排序/生成机制、默认、同步性、所有者/商业模式、组织流程与观察日期。

## 内容与媒介的识别策略

| 比较 | 主要帮助识别 | 仍然无法排除 |
|---|---|---|
| 同内容、不同配置 | 媒介候选效应 | 自选择、熟悉度、顺序效应 |
| 同配置、不同内容 | 内容候选效应 | 内容与用户目标交互 |
| 配置变更前后 | 尺度/速度/模式变化 | 同期政策、人员、市场变化 |
| 分群任务/访谈 | 差异 affordance 与结果 | 样本和表达权偏差 |

“内容完全相同”在生成系统中可能无法实现，因此须记录提示、模型、检索库、温度/排序和版本漂移。

## 竞争模型

观察到的行为变化可能来自内容质量、宣传/培训、价格、政策、网络条件或新奇效应，而非媒介结构。反过来，内容准确率不变也不能说明节奏、角色或注意未改变。

## 历史探针的边界

原书跨历史比较往往旨在打破习惯注意，不等于今天意义上的识别策略。现代使用必须补比较配置、测量、替代解释和推翻观察；否则格言可事后解释任何结果。

## 操作决定

- 不把“AI/互联网/手机”当完整媒介单位；
- 双层审计内容和配置；
- 所有当代效应标 D 层假设；
- 高风险领域先用领域证据和规则；
- 维护版本与判断更新日志。

## 未解决问题
