# 声明分层地图

本表区分 1964 原书（A）、McLuhan 后期发展（B）、后续研究/批评（C）和本 Skill 操作化（D）。`否` 表示明确禁止的归因。

| ID | 可使用的声明 | 层 | 主要来源 | 证据与使用限制 |
|---|---|---|---|---|
| M001 | 媒介的“讯息”包括其引入的人类事务之尺度、速度或模式变化 | A | UM-01, UM-02 | 不表示内容不存在、永远次要或无需事实核查 |
| M002 | McLuhan 的媒介包括技术/人的延伸，不限大众传媒 | A | UM-01, UM-03 | 仍须固定设备、界面、机制、场景与时间版本 |
| M003 | 媒介延伸能力时，也可用截除、麻木或依赖作分析探针 | A | UM-01, UM-03 | 不是任何用户都必然受同样影响的实证定律 |
| M004 | 一种媒介的内容常是另一种媒介 | A | UM-01, UM-02 | 嵌套链不能自动决定影响方向或责任 |
| M005 | hot/cool 与定义度、感官延伸和受众补全/参与有关 | A | UM-01, UM-09 | 历史设备例子不能成为现代平台永久标签 |
| M006 | 增强、退出主导、复归、反转四律主要由后期 *Laws of Media* 系统化 | B | UM-05 | 非 1964 原书现成工作流；反转不是日期预测 |
| M007 | figure/ground 与 media ecology 强调显眼内容背后的环境关系 | B/C | UM-04, UM-06 | 后续系统化阐释不能全写成原书逐字主张 |
| M008 | 技术决定论与“普遍用户”假设需由制度、文化、政治经济和差异权力修正 | C | UM-07, UM-08 | 批评不是另一种单因决定论；具体群体需数据 |
| M009 | MEDIUM 是本 Skill 创建的六步配置审计 | D | D1 | 不是 McLuhan 方法原名，也不是效应证明工具 |
| M010 | 内容层与媒介层应分开审计后再连接 | D | D1 | 内容正确不证明配置无害，配置有益不许可内容失真 |
| M011 | 延伸账应配少用能力、隐形劳动、失效后果与恢复路径 | D | D1 | 这些是待验证问题，不是自动损益表 |
| M012 | 每个媒介效应应写群体、窗口、比较配置、替代解释与推翻观察 | D | D1 | 单轮偏好或点击率不能替代长期/分群结果 |
| M013 | affordance 是技术—用户—情境间的行动可能，不是功能或结果本身 | C | UM-10 | 同一功能对不同能力/目标者可提供不同 affordance |
| M014 | 生成式 AI 审计可区分治理、模型和下游应用三个互补层次 | C | UM-11 | 蓝图论文提出结构，不证明所有审计都有效 |
| M015 | 结构化终端用户调查、讨论、核验和报告可暴露专家审计遗漏的伤害 | C | UM-12 | 单项研究/参与样本不能保证代表所有受影响者 |
| M016 | 推荐系统审计应验证真实用户控制及配置行为，而非只检查按钮存在 | C | UM-13 | 特定系统/研究方法的发现不可无条件外推 |
| M017 | “全球村落”涉及时空压缩与更强卷入，不等于全球和谐 | A | UM-01, UM-02 | 连结可能伴随冲突、监视、过载和排斥 |
| M018 | 点击、补全或纠错劳动不自动等于用户能动性 | C/D | UM-10, UM-12, D1 | 需检查拒绝、改规则、退出和影响结果的能力 |
| M019 | 同一模型在搜索、IDE、客服和会议摘要中是不同媒介配置 | D | D1 | 必须记录版本、检索、默认、设备和组织流程 |
| M020 | 固定内容的配置比较可帮助区分内容候选效应与媒介候选效应 | D | D1 | 仍受选择、学习、情境和测量混杂影响 |
| M021 | 所有权、商业模式、基础设施和规则改变权属于 ground 审计 | C/D | UM-04, UM-07, UM-08, D1 | 不应只把用户界面当完整系统边界 |
| M022 | 高风险 MEDIUM 输出只可生成分析与探针，不能批准上线 | D | D1 | 负责人/停止条件不替代法律与领域审查 |
| M023 | 当代 AI 效果必须依靠当代系统、配置和受影响群体证据 | D | D1, UM-11, UM-12 | 历史类比和经典格言不能代替经验验证 |
| M024 | 媒介配置审计应记录版本与观察日期并维护判断更新日志 | D | D1 | 配置漂移会使旧结论失效；不得静态贴标签 |

## 明确否定的归因

| 被禁止的说法 | 原因 |
|---|---|
| “内容不重要” | 错读 M001；内容和媒介须双层审计 |
| “tetrad 是 1964 原书的完整四步法” | 主要是后期 B 层，见 M006 |
| “AI 聊天天生是冷媒介” | hot/cool 依具体配置、任务和参与，见 M005 |
| “McLuhan 精确预言并证明了生成式 AI 的效果” | 历史类比不是当代证据，见 M023 |
| “平台有控制按钮，所以用户有控制” | 功能不等于 affordance 或实际结果，见 M013、M016、M018 |

## 禁止坍缩

- 媒介层重要 ≠ 内容不重要；
- 延伸 ≠ 改善，截除 ≠ 必然伤害；
- 高参与 ≠ 有能动性；
- 四律反转 ≠ 时间预测；
- 技术结构 ≠ 技术单独决定历史；
- 历史类比 ≠ 当代因果证据；
- 填完审计表 ≠ 已批准产品上线。
