# Executable Templates

## 1. Noise Qualification Gate

```markdown
- 系统与决策阶段：
- 规则/数据来源与版本：
- 系统责任人：
- 案件总体和进入/排除规则：
- 判断输出：
- 为什么这些案件/重复判断本应相同或相近：
- 可比信息集：
- 目标类型：可验证结果 / 校准专家共识 / 公开政策规则 / 无可辩护目标
- 差异可能合法的理由：
- 结论：可做系统噪音审计 / 只能探索 / 停止
```

## 2. Preregistered NOISE-AUDIT

```markdown
## N — Norm
案件、阶段、规则、版本：

## O — Observe independently
- 抽样框与样本量：
- 判断者数量、分配与盲化：
- 是否重复、间隔：
- 顺序/上下文记录：

## I — Identify components
| 成分 | 可识别所需设计 | 当前是否满足 | 不能声称什么 |
|---|---|---|---|
| 水平噪音 | 多判断者跨多个可比案件 |  |  |
| 模式噪音 | 判断者×案件特征覆盖 |  |  |
| 场合噪音 | 同一判断者重复同案 |  |  |

## S — Score
- 可靠性/离散：
- 准确性/校准（若有目标）：
- 置信区间/敏感性：

## E — Evaluate harms
- 假阳性/假阴性成本：
- 群体分层与资料缺失：
- 理由、人工复核、申诉：

## A/U/D
- 干预与机制：
- 成功/伤害/成本指标：
- 影子运行或小试：
- 责任人、回滚、停止条件：
```
