# Pass 06｜工作流综合与验证

PREFERENCE-UNCERTAIN：Consequence gate → objective/action/permission → principals/affected/veto → six-source preference register → uncertainty/non-negotiables → query budget → gaming/preference-shaping red team → sociotechnical corrigibility → constrained reversible assistance → plural/distributional evaluation → document/reopen。

验收问题：

- 高风险且不可逆是否阻断自主执行？
- observed behavior 是否与 consent/authorization 分开？
- 每个群体是否分别记录 stated/observed/informed/reflective/procedural/rights-constrained 信息？
- 权利是否作为禁行约束而非低权重效用？
- 查询是否有限额、允许不知道/退出并评估操纵与负担？
- 关闭是否跨模型、基础设施、权限、反报复、回滚、日志和争议裁决？
- 是否监测偏好塑造、少数伤害和未使用者外部性？

缺一关键门则只能研究/沙盒，不能上线。
