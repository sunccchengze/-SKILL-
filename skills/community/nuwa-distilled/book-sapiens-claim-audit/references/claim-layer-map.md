# Claim / Source Layer Map

> 规则：A 仅表示原书可归属，B 表示版本/论证语境，C 表示独立证据或反证，D 表示本 Skill 新建的操作推论。不是 18 条“已证实事实”。

| ID | 层 | 可审计主张 | 定位/来源 | 限定与反证 | 操作用途 |
|---|---|---|---|---|---|
| A-SAP-01 | A | 原书以约七万年前“认知革命”解释新语言、想象与灵活合作能力的跃迁。 | S01，Part I；S02 目录 | “革命”是叙事分期，不是已定位的单一突变。 | 建立待审计时间阈值。 |
| A-SAP-02 | A | 原书认为共同认可的想象秩序可让陌生人大规模协作。 | S01，Part I–III | 不能把必要、充分与促成因素混同。 | 生成合作机制比较。 |
| A-SAP-03 | A | 原书把农业转型描述为总食物/人口扩张与部分个体生活代价并存，并使用“最大骗局”修辞。 | S01，Part II | “骗局”不是测量变量；结果依地域、时期和群体而变。 | 拆分人口与福祉结果。 |
| A-SAP-04 | A | 原书把 Sapiens 扩散与多地巨型动物灭绝紧密联系。 | S01，Part I | 时间相邻不自动建立单因因果。 | 比较人类、气候、生态机制。 |
| A-SAP-05 | A | 原书将承认无知、观测/数学、帝国与资本并置为现代科学扩张的重要动力。 | S01，Part IV | 不是对前现代知识传统的完整学术史。 | 拆分制度、方法与权力链。 |
| B-SAP-01 | B | 《Sapiens》是跨学科大众宏观史综合，不是系统综述或单一学科专著。 | S02、S03 | 可作问题地图，不能替代专业证据评价。 | 降低体裁误读。 |
| B-SAP-02 | B | “fiction / imagined order”在书中覆盖神话、法律、货币、国家等异质对象，不能一律译成“虚假”。 | S01；S15 批评 | 主体间建构仍有现实约束和法律后果。 | 防止权利否定。 |
| B-SAP-03 | B | 版本、译文和页码会变化；书中也承认史前生活与未来路径有大量未知。 | S01、S02 | 精确引文必须回到指定版本，不能用摘要代引。 | 建立引文核验门。 |
| C-SAP-01 | C | 雕刻、颜料与装饰等象征代理在不同地点较早且异步出现，削弱单一离散阈值的强版本。 | S04、S05 | 行为代理不能直接化石化“认知”。 | 支持马赛克替代解释。 |
| C-SAP-02 | C | 古基因组证据支持 Sapiens 与 Neanderthal 之间多次基因流，简单完全替代叙事不足。 | S06 | 基因流的次数与地理范围仍受样本限制。 | 校正物种替代叙事。 |
| C-SAP-03 | C | 多项生物考古研究发现农业依赖增加常伴身高、牙病、感染或营养压力恶化。 | S07、S09 | 趋势并非每个地区同步；代理不等于总幸福。 | 支持有限健康代价。 |
| C-SAP-04 | C | 定居/耕作可同时增加疾病或死亡压力与生育率，说明人口扩张不等于个体健康改善。 | S08 | 当代 Agta 研究是机制证据，不是新石器时代直接复制。 | 分离数量和质量结果。 |
| C-SAP-05 | C | 巨型动物灭绝的案例研究支持人类影响，但气候、时序和生态脆弱性可能共同作用。 | S10 | 不同大陆、类群和年代不能用同一权重。 | 要求多因模型。 |
| C-SAP-06 | C | 大规模合作研究涉及亲缘、互惠、声誉、惩罚、规范、制度与群体竞争等机制。 | S11、S12 | 共享叙事可以是机制之一，不是自动充分解释。 | 构建机制竞争场。 |
| D-SAP-01 | D | 任一宏大主张先固定时间、空间、分析单位和比较组，再评价证据。 | 本 Skill SCALE | 这是审计规则，不是 Harari 原话。 | 防止尺度偷换。 |
| D-SAP-02 | D | 每条代理证据必须登记目标构念、桥接假设、断裂方式和来源独立性。 | 本 Skill E1–E5 | 多个共享偏差的代理不能靠数量升级。 | 建立证据桥。 |
| D-SAP-03 | D | 结论必须与至少一个强替代解释和会改变判断的新证据同场呈现。 | 本 Skill Locate/Update | 不是机械“平衡双方”，而是比较可检验预测。 | 反证与更新。 |
| D-SAP-04 | D | 历史解释不得直接推出族群价值、现代权利或领土结论；高风险使用需责任、社群咨询、异议和停止门。 | 本 Skill safety gate | 权利不是由单一史前叙事授予或取消。 | 阻断下游伤害。 |
