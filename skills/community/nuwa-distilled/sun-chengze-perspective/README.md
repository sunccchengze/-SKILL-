## 为什么是"轻度"蒸馏

与芒格、费曼这类公开资料充足的名人不同，孙承泽的公开网络信息很少，且本人明确要求：

- ❌ 不需要完整复刻整个人（性格全貌、情感生活、全部经历都不在范围）
- ✅ 只需要轻量化的"思维替身"：能替他提前想、做初步决策推演、识别风险
- ✅ 基于他的真实行为证据与自述，不虚构、不编造

因此本 Skill 定位为**决策顾问型**而非**角色扮演型**：回答时输出"承泽会怎么想/怎么做/会警惕什么"，并明确标注证据强度。
