## 1. 打脸链路（Predict → Fail → Reconstruct）
- **定义**：预测 → 实验/实践 → 打脸 → 自驱重构。把"被打脸"当作学习信号而不是挫败。（高）
- **出处**：GROWTH_ROADMAP.md「你是谁（诊断基础）」：*打脸链路学习者——预测→实验打脸→自驱重构*；zixue2026 学习系统将其命名为 "predict-fail-reconstruct"。
- **配套心态**：「低自信型答对者——良知已知，只是不敢信」（高）。即答案其实知道，但对自己的判断信心不足，需要实验来背书。
- **理论锚点**（成长路线图给出的映射）：OODA 循环 = 贝叶斯更新 = 知行合一 = 痛苦+反思。

## 2. 借鉴 → 创造性转化 → 固化为自己的体系
- **定义**：拿到第三方优秀理论/技能库，先消化吸收，再改造成自己的工程流水线，最终固化为可复用的护城河。（高）
- **实例**：
  - 把 1.1GB / 37,600+ 文件的开源技能生态用 git submodule 引入，用"女娲蒸馏技术 + AI 内阁五方红蓝对抗法"改造成叶轮机械平台专属流水线（高，个人档案原文）；

  - zixue2026：238 技能 → 12 学习轨道 → 打脸链路学习操作系统（高）。

## 第一轮访谈补充（2026-08-31，一手自述）

### 打脸链路的完整表述（用户原话精要）
- 从小到大的人生信条，不是某个项目教会他的："失败是成功之母，不多尝试几次，怎么可能知道它的真正原理？"
- 三要素：**预测**（凭直觉或先做烂成果）→ **实验** → **打脸修正**。"不管会不会、敢不敢，都要尝试一下"。
- 防拖延功能：等想完美再做 = 违背王阳明"知行合一"；要持续进步、在反馈中迭代。
- 反面：闭门造车 / 只输入不输出（考试必须模拟考+刷题）。
- 错误的价值："错误总比成功带来更深刻的记忆"，用错误巩固正确认知。

### 借鉴→转化→固化（用户原话精要）
- 借鉴只是第一步；必须"由我这个个体介入"转化到自己的环境（个体不同、环境不同、经验不能完全套用）。
- 创造性转化 = 打破信息茧房 + 拿出与别人不一样的东西（普遍的东西不会引起轰动）。
- 宇宙级论证：46 亿年地球、几百万年人类、80 亿人 → 想做的事一定有人做过，成功经验定路线、失败经验避坑，甚至只需观察其思维方式。
- 大模型蒸馏类比：教师模型→学生模型，参数量极小却保留大部分能力 → AI 市场由此滚滚向前。
- 结论："借鉴是这个时代非常宝贵的能力，蒸馏是 AI 时代赋予普通人和学生的一个超级大宝藏。"（这也是他喜欢女娲的原因）

### AI 辅助决策流程（Q4 补充，决策方法新证据）
- 决策前：把想法告诉 AI → 多轮校对 → 确保无问题再执行；
- 让 AI 全网搜集信息、深度消化仓库内容、深度调研 → 充分掌握信息后再决断；
- 防止两类错误：情绪化冲动、完美主义死磕（80% 可交磨到 95%）。

## 第四轮访谈补充（2026-09-01，一手自述）

### 实力主义 / 反平庸驱动（方法论级信念，高）
- 核心恐惧 = 平庸；解法 = 变强："**只有本身这个实力没有达到一定层次的人才会担心自己变得平庸。当自己足够强的时候，你就不可能平庸了。**"
- 与延迟满足同源：一直努力变强，直到"实力足够雄厚"，就不用担心不出彩。

### 心想事成行动路径（高）
- "我想啥我就去做什么事情，我就是一个随心所欲的状态。**我想要什么我就一定要得到，然后我就会为此而努力**——这就是我的行动路径。"
- 灵机一动 → 立刻动手：英仔招新网站即此产物（自述"心想事成的体现"）。

### 精力管理学（社交节能模式，高）
- 自认核心优点：灵活调节社交与工作——给人良好第一印象的同时，**不让社交深入占用时间精力**，"把自己的精力保存起来"。
- 与 INTJ 社交策略（外热内冷）机制互补：礼貌面具用于省能，而非索取。

### 深度工作开关（高）
- 待机态：可懒、可放松（"有时候挺懒的，也挺放松的"）；
- 触发态："**只要有事来了之后，可以立刻进入工作状态，然后很长时间都不被打断。**"
