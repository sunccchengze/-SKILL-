## 1. 蒸馏任务

目标不是把原书压成格言，而是保存其独特推理动作：

1. 以连续问答暴露概念前提；
2. 从局部利害移动到系统边界；
3. 区分体与用、条件与结果；
4. 在可控的人事与不可控残余之间分配责任；
5. 从线性小变化识别阈值风险；
6. 依时、事调整方法，同时守住现代权利和证据边界。

## 5. 模型验证记录

### M1 利害递归

- 原文结构：从鱼利水、人利陆，转到饵与财可能成为害。
- 原理：价值不是孤立属性，而是主体—对象—条件关系。
- 迁移1（产品）：便利对用户有利，但隐私成本可能外包。
- 迁移2（政策）：补贴利于当前行业，长期可能固化低效。
- 迁移3（个人）：加薪有利，若伴随不可恢复健康损害则净值翻转。
- 反例：所有远端影响都纳入会无法决策。
- 限定：只纳入会显著改变选项排序的外部性。

### M2 体用相依

- 原文结构：体无定用、用无定体，变化中互见。
- 原理：工具价值由功能和条件共同决定。
- 迁移：技术栈、组织角色、资产再利用。
- 反例：某些规范价值（人的尊严）不应按“用”定价。
- 限定：只用于资源/方案，不将人降为工具。

### M3 观物以理

- 原文结构：目观形、心观情、理观其所以。
- 原理：从描述进入机制。
- 迁移：根因分析、研究设计、战略因果图。
- 反例：抽象“理”可能不可证伪。
- 限定：每个机制附竞争解释与观测。

### M4 六具与天时

- 原文结构：六物具仍可能不得鱼，不具则无由得鱼。
- 原理：必要条件与充分结果分离。
- 迁移：考试、项目、创业。
- 反例：无法因一次得失判断条件因果。
- 限定：看重复数据或有区分力的过程指标。

### M5 力分阈值

- 原文结构：百斤无伤，加十斤遂伤。
- 原理：接近边界时小增量触发大后果。
- 迁移：服务负载、人员工作量、现金流。
- 反例：某些系统近似线性；容量会训练增长。
- 限定：用现实测量估计，不把寓言当数值。

### M6 时事权变

- 原文结构：消长为时、轻重为事，策略随状态。
- 原理：环境和事件权重共同决定动作。
- 迁移：市场进入、事件响应、组织改革。
- 反例：借权变逃避承诺。
- 限定：原则、法规、权利不作为可变参数。

## 6. 从对话到算法

### 6.1 问句生成器

给定主张 `X 导致 Y，因此应做 A`：

```text
Q1 术语：X、Y、A 分别可观察为何物？
Q2 条件：X 通过什么过程导致 Y？
Q3 竞争：还有什么也会产生 Y？
Q4 边界：对谁是 Y，对谁不是？
Q5 体用：A 是唯一载体，还是只是一种实现？
Q6 条件：A 的必要条件齐吗？仍有哪些残余？
Q7 阈值：规模/时间改变时，关系何处翻转？
Q8 行动：哪项观测最能改变决策？
```

### 6.2 深度控制

每层追问必须至少满足一项：

- 能改变方案排序；
- 能暴露重大风险；
- 能区分竞争解释；
- 能定义责任或停止条件。

否则停止。

### 6.3 输出校准

- 原文：用引号并定位论证段落。
- 释义：说明是对原文结构的理解。
- 操作化：明确为现代工作流。
- 事实判断：使用现实数据和来源。
- 价值判断：显式说明标准，不伪装成事实。

## 7. 矛盾与保留

| 张力 | 不能删掉的两面 | 运行处理 |
|---|---|---|
| 人/天 | 准备有责任；结果有残余 | 可控账本+失败预算 |
| 物/我 | 需超越局部；视角无法消失 | 四层边界+位置披露 |
| 体/用 | 功能变化；载体有连续成本 | 替代设计+迁移成本 |
| 理/验 | 机制抽象；经验核验 | 竞争解释+观测 |
| 变/常 | 策略适配；原则连续 | 触发器+硬边界 |
| 个体/整体 | 整体外部性；个体权利 | 缺席者入账+权利底线 |

## 8. 拒绝的浅层蒸馏

- “顺应天时就会成功”——删除：把必要条件与保证混淆。
- “看透万物之理”——删除：不可证伪且鼓励权威姿态。
- “人算不如天算，所以不必强求”——删除：抹去可控责任。
- “整体利益高于个人”——删除：可为侵害权利开脱。
- “无用之物经变化总会有用”——过度普遍化，改为体用假设。
- “加一点就一定崩溃”——误读阈值；只有接近边界才成立。

## 9. 验收案例

### 正向

1. 技术上线：应产出体用、条件、外部性、容量和试点触发器。
2. 组织重组：应检查对谁有利、激励变化和长期能力。
3. 项目失败：应区分条件缺失、机制错误和随机结果。
4. 价值争论：应分事实、机制和价值，不用一个“理”压平。

### 边界

1. 占卜婚期：拒绝预测；转为现实约束和触发器。
2. 医疗剂量：不以“力分”计算；建议专业医疗。
3. 桥梁载荷：不以百斤比喻给安全系数；调用工程标准。
4. 社会达尔文判断：拒绝以治乱对人群贴道德标签。

### 最小通过标准

- [ ] 至少连续追问两层，但触发停问规则。
- [ ] 明确主体、时间和系统边界。
- [ ] 区分必要条件与成功保证。
- [ ] 至少一个替代载体/方案。
- [ ] 至少一个阈值或翻转条件。
- [ ] 比喻没有代替证据。
- [ ] 保留不可控残余但没有宿命化。
- [ ] 输出有下一步与复审触发器。
